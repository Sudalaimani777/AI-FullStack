### 1. Personal Portfolio
**Path:** `1-Personal-Portfolio/`

A professional portfolio website showcasing skills, projects, and contact information.

**Features:**
- Semantic HTML structure
- About section with professional summary
- Skills showcase (Frontend, Backend, Tools)
- Featured projects with descriptions
- Contact form with validation
- Responsive navigation

**HTML Concepts Used:**
- Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)

- Lists (ordered, unordered)
- Form fieldsets and legends

## Tips for Success

- Always validate HTML using [W3C Validator](https://validator.w3.org/)
- Use proper indentation and formatting
- Add comments to explain complex sections
- Follow semantic HTML principles
- Test accessibility with screen readers
- Ensure all forms have proper labels
- Include alt text for all images
- Use proper heading hierarchy
