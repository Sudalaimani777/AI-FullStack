3. Description List (Term-Definition Pairs)

Description lists use <dl> for the list, <dt> for terms, and <dd> for definitions. Perfect for glossaries, metadata, or key-value pairs.

The standard markup language for creating web pages. It structures content with elements like headings, paragraphs, and links.
CSS (Cascading Style Sheets)
A stylesheet language used to describe the presentation of HTML documents. Controls colors, layouts, fonts, and responsive design.
JavaScript
A programming language that enables interactive features on websites, from simple animations to complex web applications.
DOM (Document Object Model)
A programming interface for HTML documents. Represents the page structure as a tree of objects that can be manipulated with JavaScript.
API (Application Programming Interface)
A set of rules and protocols that allows different software applications to communicate and exchange data with each other.

📌 Summary: When to Use Each List Type

  • Unordered Lists (<ul>): Items without specific order - features, benefits, ingredients
  • Ordered Lists (<ol>): Sequential items - steps, rankings, instructions
  • Description Lists (<dl>): Term-definition pairs - glossaries, metadata, FAQs
  • Nested Lists: Hierarchical content - categories with subcategories, file structures
  • Accessibility: Screen readers announce list types and item counts
  • SEO Benefits: Search engines understand structured content better
  • Best Practice: Choose the semantic list type that matches your content
