HTML Accessibility (A11y)

Learn how to make your HTML accessible to everyone

Topics to Cover:

1. Semantic HTML

Use meaningful HTML tags instead of generic <div> and <span>

  • <header>, <nav>, <main>, <footer>
  • <article>, <section>, <aside>

2. Headings Hierarchy

  • Use h1, h2, h3... in logical order
  • Only one h1 per page
  • Don't skip heading levels

3. Alt Text for Images

<img src="photo.jpg" alt="A person sitting on a bench">
  • Always include descriptive alt text
  • For decorative images, use empty alt=""

4. Form Labels

<label for="username">Username:</label> <input type="text" id="username" name="username">

Connect labels to inputs with 'for' attribute

5. Link Text

  • ❌ Don't: <a href="page.html">Click here</a>
  • ✓ Do: <a href="page.html">View our services</a>

6. Color Contrast

Ensure sufficient color contrast between text and background

WCAG AAA: Contrast ratio of at least 7:1

7. Keyboard Navigation

  • All interactive elements should be keyboard accessible
  • Use tabindex wisely
  • Visible focus indicators

8. ARIA (Accessible Rich Internet Applications)

<button aria-label="Close menu">×</button>
  • aria-label - Labels for unlabeled elements
  • aria-describedby - Additional description
  • role - Defines element purpose

9. Skip Links

<a href="#main-content">Skip to main content</a>

Helps keyboard users bypass navigation

10. Testing Accessibility

  • Use screen readers (NVDA, JAWS)
  • Keyboard navigation testing
  • Color contrast checkers
  • Automated tools (axe, Lighthouse)
