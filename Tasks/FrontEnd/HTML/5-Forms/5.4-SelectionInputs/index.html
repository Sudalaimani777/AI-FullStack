🎯 Selection Inputs

Dropdowns, radio buttons, and checkboxes

Dropdown Selection

Use <select> for choosing one option from a list. Perfect when you have many options and want to save space.

<!-- Dropdown Select --> <label for="country">Country</label> <select id="country" name="country"> <option value="">-- Select a country --</option> <option value="usa">United States</option> <option value="canada">Canada</option> <option value="uk">United Kingdom</option> </select>

Radio Buttons

Use radio buttons when users must select exactly one option from a small set of choices (2-5 options). All radio buttons in a group must share the same name attribute.

<!-- Radio Buttons (Single Selection) --> <input type="radio" id="shipping-standard" name="shipping" value="standard" > <label for="shipping-standard">Standard Shipping</label> <input type="radio" id="shipping-express" name="shipping" value="express" > <label for="shipping-express">Express Shipping</label> <!-- All radio buttons must have same 'name' -->

Checkboxes

Use checkboxes when users can select multiple options or toggle a single option on/off. Each checkbox can have a unique name, or use the same name with different values for arrays.

<!-- Checkboxes (Multiple Selection) --> <input type="checkbox" id="interest-web" name="interests" value="web-development" > <label for="interest-web">Web Development</label> <input type="checkbox" id="interest-mobile" name="interests" value="mobile-apps" > <label for="interest-mobile">Mobile App Development</label> <!-- Same 'name' creates an array of values -->

✅ Selection Input Best Practices

  • Use dropdowns for many options: More than 5 options? Use a select dropdown
  • Radio buttons for visibility: When all options should be visible (2-5 choices)
  • Checkboxes for independence: Each option can be selected independently
  • Always use labels: Connect labels to inputs with for/id attributes
  • Group related items: Use same name attribute for radio button groups
  • Provide clear descriptions: Explain what each option means
  • Set logical defaults: Pre-select the most common choice when appropriate
  • Make it accessible: Ensure keyboard navigation and screen reader compatibility
