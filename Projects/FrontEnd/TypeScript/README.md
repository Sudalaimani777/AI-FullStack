## 🏗️ Architecture & Core TypeScript Concepts

- **Interface Contracts**: Enforcing precise data shapes across models and template renderers.
- **Singleton Design Pattern**: Guaranteeing single global instances for state collections (`FullList`) and UI renderers (`ListTemplate`).
- **DOM Manipulation in TS**: Safe type casting (`HTMLFormElement`, `HTMLInputElement`, `HTMLButtonElement`) for event handling.
- **Vite & TS Compiler Pipeline**: Rapid compilation via Vite with static type checking using `tsc`.

## 🚀 Quickstart Execution Guide

1. **Navigate to project directory**:
   ```bash
   cd Projects/FrontEnd/TypeScript/1-TodoApp
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build type checking & bundle**:
   ```bash
   npm run build
   ```
