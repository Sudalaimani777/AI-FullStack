# 💰 Money Tracker App

A modern, responsive money tracking application built with vanilla JavaScript and Tailwind CSS. Track your expenses and income with a beautiful, animated user interface and persistent data storage through REST API integration.

## ✨ Features

### 🎯 Core Functionality
- **Add Transactions** - Record your expenses and income with task names and amounts
- **Update Transactions** - Edit existing transactions when details change
- **Delete Transactions** - Remove individual transactions
- **Clear All** - Quickly clear all transactions at once
- **Real-time Total** - Automatically calculated total balance
- **Persistent Storage** - Data stored via REST API (MockAPI.io)

### 🎨 Modern UI/UX
- **Responsive Design** - Works seamlessly on mobile, tablet, and desktop devices
- **Smooth Animations** - Slide-down, fade-in, and hover effects
- **Gradient Backgrounds** - Beautiful indigo-to-pink gradient themes
- **Interactive Elements** - Hover effects with lift and scale transformations
- **Modern Cards** - Rounded corners with shadow effects
- **Icon Integration** - Font Awesome icons for better visual experience

### 🏗️ Architecture
- **MVC Pattern** - Clean separation of concerns with Data, UI, and App controllers
- **IIFE Modules** - Encapsulated code using Immediately Invoked Function Expressions
- **Async/Await** - Modern asynchronous JavaScript for API operations
- **REST API Integration** - Full CRUD operations (Create, Read, Update, Delete)

## 🚀 Quick Start

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection (for Tailwind CDN and Font Awesome icons)

### Installation

1. **Clone or download this project**
   ```bash
   git clone <repository-url>
   cd MoneyTracker/3-FinalStageWithAPI
   ```

2. **Open the application**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js http-server
     npx http-server
     
     # Using VS Code Live Server extension
     Right-click index.html > Open with Live Server
     ```

3. **Start tracking!**
   - The app will automatically load existing transactions from the API
   - Start adding your transactions immediately

## 📖 How to Use

### Adding a Transaction
1. Enter the task/expense name in the "Task Name" field
2. Enter the amount in the "Amount (₹)" field
3. Click the **"Add Task"** button
4. The transaction appears in the list below with the total updated

### Editing a Transaction
1. Click the **pencil icon** (✏️) on any transaction
2. The task name and amount populate the input fields
3. Modify the values as needed
4. Click the **"Update"** button to save changes
5. Click **"Back"** to cancel editing

### Deleting a Transaction
1. Click the **pencil icon** on the transaction to edit
2. Click the **"Delete"** button
3. The transaction is removed and total is updated

### Clearing All Transactions
- Click the **"Clear All"** button in the top-right navigation
- All transactions will be permanently removed

## 🛠️ Technical Details

### Tech Stack
- **HTML5** - Semantic markup structure

- **Font Awesome 6** - Icon library

### API Endpoints
Base URL: `https://697637efc0c36a2a99508a09.mockapi.io/api/v1/task`

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/task` | Fetch all transactions |
| POST | `/task` | Create new transaction |
| PUT | `/task/:id` | Update transaction by ID |
| DELETE | `/task/:id` | Delete transaction by ID |

### Data Model

  id: string,        // Unique identifier (generated by API)

### Code Architecture

#### Data Controller (`dataController`)
Handles all data operations and API interactions:
- `loadItem()` - Fetch transactions from API
- `addNewData()` - Create new transaction
- `updateItem()` - Update existing transaction
- `deleteItem()` - Delete single transaction
- `clearAllItems()` - Delete all transactions
- `getTotalMoney()` - Calculate total balance
- `getItemById()` - Retrieve specific transaction
- `setCurrentItem()` / `getCurrentItem()` - Manage editing state

#### UI Controller (`uiController`)
Manages all UI updates and rendering:
- `populateData()` - Render transactions to UI
- `showTotalMoney()` - Display total balance
- `clearInputFields()` - Reset form inputs
- `showEditBtns()` / `clearBtnState()` - Toggle button visibility
- `addItemToForm()` - Populate form for editing
- `updateListItem()` - Update UI after edit
- `deleteListItem()` - Remove item from UI
- `clearAllItemsUI()` - Clear all items from UI

#### App Controller (`appController`)
Coordinates user interactions and event handling:
- `appStart()` - Initialize application
- `loadAllEventListeners()` - Register all event listeners
- `addMoneyAndTaskEvent()` - Handle adding transactions
- `handleEdit()` - Handle edit icon clicks
- `itemDeleteSubmit()` - Handle delete operations
- `itemEditSubmit()` - Handle update operations
- `itemBackSubmit()` - Handle back button
- `clearSubmit()` - Handle clear all action

## 🎨 Customization

### Changing Colors
The app uses gradient color schemes. To customize, edit the Tailwind classes in `index.html`:

```html
<!-- Current: Indigo to Purple -->
<nav class="bg-gradient-to-r from-indigo-600 via-purple-600 to-pink-600">

<!-- Example: Blue to Teal -->
<nav class="bg-gradient-to-r from-blue-600 via-teal-600 to-cyan-600">
```

### Modifying Animations
Custom animations are defined in the `<style>` section of `index.html`:
- `slideDown` - Entry animation for new items
- `fadeIn` - Fade-in effect for cards
- `hover-lift` - Lift effect on card hover

### API Configuration
To use a different API backend, update the `API_URL` in `script.js`:
```javascript
const API_URL = "https://your-api-endpoint.com/api/v1/task"
```

## 👨‍💻 Developer Notes

### Design Pattern: MVC
The application follows the Model-View-Controller pattern:
- **Model** (Data Controller): Manages data and business logic
- **View** (UI Controller): Handles presentation and rendering
- **Controller** (App Controller): Coordinates user interactions

### Why IIFE?
Immediately Invoked Function Expressions (IIFE) are used to:
- Encapsulate code and prevent global scope pollution
- Create private variables and methods
- Provide a clean public API through the return object

### Async/Await Pattern
All API operations use async/await for:
- Cleaner, more readable asynchronous code
- Better error handling with try/catch blocks
- Sequential operation flow when needed
