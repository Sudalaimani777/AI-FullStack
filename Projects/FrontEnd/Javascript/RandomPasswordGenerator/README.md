# Random Password Generator

A simple and elegant web application that generates secure random passwords with one click.

## Features

- 🔐 Generates 12-character random passwords
- 🎲 Includes uppercase letters, lowercase letters, numbers, and special characters
- 📋 One-click copy to clipboard functionality
- 📱 Fully responsive design
- ✨ Clean and intuitive user interface
- 🎨 Styled with Tailwind CSS

## Technologies Used

- **HTML5** - Structure and markup
- **JavaScript (ES6)** - Password generation logic and DOM manipulation
- **Tailwind CSS** - Styling and responsive design
- **Font Awesome** - Copy icon

## How to Use

1. Open `index.html` in your web browser
2. Click the **Generate** button to create a random password
3. The password will appear in the input field
4. Click the **copy icon** inside the input field to copy the password to your clipboard
5. A success alert will confirm the password has been copied

## Password Characteristics

- **Length**: 12 characters
- **Character Set**: 
  - Lowercase letters (a-z)
  - Uppercase letters (A-Z)
  - Numbers (0-9)
  - Special characters (!@#$%^&*())
