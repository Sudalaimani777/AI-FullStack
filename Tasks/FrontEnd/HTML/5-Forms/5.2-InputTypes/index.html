type="text"

Standard text input for any single-line text data.

  • Most common input type
  • Default if type is not specified
  • Accepts any text characters

type="email"

Email address input with built-in validation.

  • Validates @ symbol and domain
  • Shows email keyboard on mobile
  • Prevents submission if invalid

type="password"

Secure password input that masks characters.

  • Hides input as dots/asterisks
  • Prevents shoulder surfing
  • Use with autocomplete="off" for security

type="tel"

Phone number input optimized for mobile.

  • Shows numeric keyboard on mobile
  • No automatic validation
  • Use pattern attribute for validation

type="url"

URL input with protocol validation.

  • Validates http:// or https://
  • Shows URL keyboard on mobile
  • Includes .com button on iOS

type="number"

Numeric input with increment controls.

  • Spinner controls (up/down arrows)
  • min, max, step attributes
  • Only accepts numeric values

type="date"

Date picker with calendar interface.

  • Native calendar picker
  • Format: YYYY-MM-DD
  • min/max for date ranges

✅ Input Type Best Practices

  • Use specific types: Always use the most appropriate input type for better UX
  • Mobile optimization: Correct input types show proper keyboards on mobile devices
  • Built-in validation: HTML5 types provide free validation (email, url, number)
  • Accessibility: Proper input types help screen readers understand field purpose
  • Placeholders as examples: Show expected format but don't replace labels
  • Add constraints: Use min, max, step, pattern attributes for better validation
  • Progressive enhancement: Forms still work if browser doesn't support new types
