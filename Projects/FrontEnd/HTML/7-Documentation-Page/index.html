Introduction to HTML

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using a series of elements represented by tags.

HTML5 is the latest evolution of the standard that defines HTML. It includes new elements, attributes, and behaviors, and a larger set of technologies that allow building more diverse and powerful websites and applications.

"HTML is the foundation of all web pages. Without HTML, you can't create a website."

Getting Started

Basic HTML Document Structure

Every HTML document follows this basic structure:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document Title</title>
</head>
<body>
    <!-- Your content here -->
</body>
</html>

Understanding the Structure

<!DOCTYPE html>
Declares the document type and HTML version (HTML5)
<html>
Root element that wraps the entire HTML document
<head>
Contains metadata about the document (not visible on page)
<body>
Contains all visible page content

Basic HTML Elements

Headings

HTML provides six levels of headings, from <h1> to <h6>.

Syntax

<h1>Main Heading</h1>
<h2>Subheading</h2>
<h3>Sub-subheading</h3>

Best Practices

  • Use only one <h1> per page
  • Don't skip heading levels (e.g., h1 → h3)
  • Use headings for structure, not styling
Heading Hierarchy
Tag Purpose SEO Importance
<h1> Main page title Highest
<h2> Major sections High
<h3> Sub-sections Medium
<h4-h6> Further subdivisions Lower

Paragraphs

The <p> element represents a paragraph of text.

Syntax

<p>This is a paragraph.</p>

Related Elements

  • <br> - Line break (use sparingly)
  • <hr> - Horizontal rule (thematic break)

Links

The <a> (anchor) element creates hyperlinks.

Syntax

<a href="https://example.com">Link Text</a>

Link Types

Type Example Description
External href="https://example.com" Links to another website
Internal href="/about.html" Links within same site
Anchor href="#section" Links to page section
Email href="mailto:email@example.com" Opens email client
Phone href="tel:+1234567890" Initiates phone call

Important Attributes

href
Specifies the URL destination
target
Where to open the link (_blank, _self, _parent, _top)
rel
Relationship between pages (noopener, nofollow, etc.)
title
Additional information (tooltip)

Images

The <img> element embeds images in a document.

Syntax

<img src="image.jpg" alt="Description" width="300" height="200">

Required Attributes

Attribute Purpose Required?
src Image source/path ✓ Yes
alt Alternative text (accessibility) ✓ Yes
width Image width in pixels ✗ Optional
height Image height in pixels ✗ Optional
loading Lazy loading (lazy/eager) ✗ Optional

Important: Always include descriptive alt text for accessibility!

Text Formatting

Semantic Text Tags

These tags provide meaning, not just appearance:

Tag Purpose Example
<strong> Important text Important
<em> Emphasized text Emphasized
<mark> Highlighted text Highlighted
<del> Deleted text Deleted
<ins> Inserted text Inserted
<code> Code snippet console.log()
<abbr> Abbreviation HTML

Presentational Tags

These affect appearance but lack semantic meaning:

  • <b> - Bold text
  • <i> - Italic text
  • <u> - Underlined text
  • <sub> - Subscript (H2O)
  • <sup> - Superscript (23)
  • <small> - Smaller text

Recommendation: Prefer semantic tags when possible!

Lists

Unordered Lists

Create bullet-point lists with <ul> and <li>:

<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>

Ordered Lists

Create numbered lists with <ol> and <li>:

<ol>
    <li>First step</li>
    <li>Second step</li>
    <li>Third step</li>
</ol>

Ordered List Attributes

Attribute Values Description
type 1, A, a, I, i Numbering style
start Number Starting number
reversed Boolean Count backwards

Description Lists

Create term-definition pairs with <dl>, <dt>, and <dd>:

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>
    
    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>
</dl>

Tables

HTML tables display tabular data using rows and columns.

Basic Table Structure

<table>
    <thead>
        <tr>
            <th>Header 1</th>
            <th>Header 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Data 1</td>
            <td>Data 2</td>
        </tr>
    </tbody>
</table>

Table Elements

Element Description
<table> Container for the table
<thead> Groups header rows
<tbody> Groups body rows
<tfoot> Groups footer rows
<tr> Table row
<th> Table header cell
<td> Table data cell
<caption> Table title/caption

Note: Don't use tables for layout! Use CSS Grid or Flexbox instead.

Forms

Forms collect user input and submit data to a server.

Basic Form Structure

<form action="/submit" method="POST">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" required>
    
    <button type="submit">Submit</button>
</form>

Common Input Types

Type Purpose Example
text Single-line text input <input type="text">
email Email address <input type="email">
password Hidden password <input type="password">
number Numeric input <input type="number">
date Date picker <input type="date">
checkbox Multiple selections <input type="checkbox">
radio Single selection <input type="radio">
file File upload <input type="file">

Semantic HTML

Semantic elements clearly describe their meaning to both the browser and the developer.

Why Use Semantic HTML?

  1. Accessibility: Screen readers can navigate better
  2. SEO: Search engines understand content structure
  3. Maintainability: Code is easier to read and maintain
  4. Standards: Future-proof and standards-compliant

Semantic vs Non-Semantic

Semantic Non-Semantic Purpose
<header> <div class="header"> Page header
<nav> <div class="nav"> Navigation
<main> <div class="main"> Main content
<article> <div class="article"> Independent content
<section> <div class="section"> Thematic grouping
<aside> <div class="sidebar"> Sidebar content
<footer> <div class="footer"> Page footer

Accessibility (A11y)

Making HTML accessible ensures everyone can use your website, including people with disabilities.

Key Principles

Perceivable
Information and UI must be presentable to users in ways they can perceive
Operable
UI components and navigation must be operable
Understandable
Information and operation of UI must be understandable
Robust
Content must be robust enough to work with assistive technologies

Best Practices

  • Always include alt text for images
  • Use proper heading hierarchy (h1 → h2 → h3)
  • Label all form inputs
  • Ensure sufficient color contrast
  • Make all functionality keyboard-accessible
  • Use ARIA attributes when necessary
  • Provide skip navigation links

HTML Best Practices

Document Structure

  • ✓ Always declare DOCTYPE
  • ✓ Include language attribute on <html>
  • ✓ Set character encoding to UTF-8
  • ✓ Include viewport meta tag for responsive design

Code Quality

  • ✓ Use lowercase for tags and attributes
  • ✓ Always quote attribute values
  • ✓ Close all tags properly
  • ✓ Indent nested elements consistently
  • ✓ Add comments for complex sections
  • ✓ Validate HTML with W3C validator

Performance

  • ✓ Minimize file size
  • ✓ Optimize images before using
  • ✓ Use lazy loading for images
  • ✓ Minimize HTTP requests
  • ✓ Place scripts at bottom or use defer/async

Common Mistakes to Avoid

  • ✗ Missing closing tags
  • ✗ Skipping heading levels
  • ✗ Using tables for layout
  • ✗ Missing alt attributes on images
  • ✗ Not labeling form inputs
  • ✗ Using inline styles everywhere
