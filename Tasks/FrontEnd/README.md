## 🛤️ Learning Path

The recommended learning sequence:

```
1. HTML → 2. JavaScript → 3. AJAX → 4. React
   ✅           📚              📚          📚
```

### Why This Order?

1. **HTML (Foundation)** - Structure and semantics of web pages
2. **JavaScript (Logic)** - Programming fundamentals and DOM manipulation
3. **AJAX (Communication)** - Asynchronous data fetching and API integration
4. **React (Framework)** - Modern component-based UI development

## 🚀 Getting Started

### Prerequisites

- Basic computer literacy
- Text editor (VS Code recommended)
- Modern web browser (Chrome, Firefox, Edge)
- Git for version control (optional)

### How to Use This Repository

1. **Start with HTML**: Complete all 25 HTML tasks before moving forward
2. **Follow the order**: Each module builds upon the previous one
3. **Practice daily**: Consistency is key to mastering frontend development
4. **View in browser**: All files are functional - open them to see results
5. **Experiment**: Modify examples to deepen understanding

### Opening Files

```bash
# Navigate to any task folder
cd Tasks/FrontEnd/HTML/1-Basics

# Open in VS Code
code index.html

# Or open directly in browser
start index.html  # Windows
open index.html   # macOS
```
