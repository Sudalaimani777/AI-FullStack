## Topics Breakdown

### 1-Start (5 tasks)
HTML/JS setup, Hello World, comments, welcome messages

### 2-Console (5 tasks)
log(), error(), warn(), info() methods

### 3-Variables (5 tasks)
var vs let vs const, re-declaration, re-assignment, naming conventions

### 4-DataTypes (5 tasks)
Strings, numbers, booleans, null, undefined, arrays, primitives vs references

### 5-TypeConversion (5 tasks)
Number(), parseInt(), String(), toString(), Boolean(), implicit conversion

### 6-Numbers (5 tasks)
Arithmetic operations, Math methods, random numbers, calculator program

### 7-Strings (5 tasks)
length, toUpperCase(), toLowerCase(), slice(), substring(), charAt(), indexOf(), replace(), split(), join()

### 8-TemplateString (5 tasks)
Multi-line strings, interpolation, calculations, HTML templates

### 9-ArrayMethods (5 tasks)
Custom implementations: indexOf(), lastIndexOf(), push(), pop(), shift(), unshift(), includes()

### 10-Objects (15 tasks)
**Main:** Object creation, property access, nested objects, methods, 'this' keyword  
**1-Constructor-This:** Constructor functions, 'new' keyword, 'this' contexts  
**2-Built-in-Constructor:** String(), Number(), Array(), Object() vs literals

### 11-IfElse (5 tasks)
if-else, else-if, logical operators, ternary operator, voting eligibility

### 12-Switch (5 tasks)
Switch cases, default, day of week, multiple cases, switch vs if-else

### 13-Functions (5 tasks)
Function declarations, expressions, arrow functions, default parameters, return values

4. Use comments to explain code
5. Mark completed tasks in `tasksList.txt`
