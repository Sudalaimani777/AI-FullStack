🖼️ Task 3.1: Basic Images

Demonstrating proper image attributes and usage

1. Image with src and alt Attributes

The most basic image implementation. The alt attribute is crucial for accessibility and SEO.

<img src="landscape.jpg" alt="Beautiful mountain landscape at sunset">
✅ Essential: Always include alt text

2. Image with Width and Height Attributes

Specifying dimensions helps prevent layout shifts when the page loads. The browser reserves space for the image.

<img src="banner.jpg" alt="Company banner" width="500" height="300">
⚡ Performance: Prevents layout shifts (CLS)

3. Image with Title Attribute (Tooltip)

The title attribute displays a tooltip when hovering over the image. Hover over the image below to see it!

<img src="tooltip-demo.jpg" alt="Demo image" title="This is a helpful tooltip!">
💡 UX: Provides additional context

4. Image from Relative Path

Images stored locally in your project. Common folder structures: ./images/, ../assets/, ./img/

<!-- Same directory --> <img src="photo.jpg" alt="Product photo"> <!-- Images subfolder --> <img src="images/photo.jpg" alt="Product photo"> <!-- Parent directory --> <img src="../assets/logo.png" alt="Company logo">
📂 Best Practice: Organize images in folders

5. Image from External URL (Absolute Path)

Loading images from external sources. Note: This requires an internet connection and depends on external server availability.

<img src="https://example.com/images/photo.jpg" alt="External image"> <!-- Using a CDN --> <img src="https://cdn.example.com/v1/banner.jpg" alt="Banner from CDN">
⚠️ Consider: External dependency and loading time

📋 Key Takeaways - Essential Image Attributes

  • src: Specifies the path to the image file (required)
  • alt: Alternative text for accessibility and SEO (required)
  • width & height: Dimensions to prevent layout shifts
  • title: Tooltip text shown on hover
  • Relative paths: For local images (./images/photo.jpg)
  • Absolute URLs: For external images (https://...)
  • Best Practice: Always include meaningful alt text
  • Performance: Specify dimensions when possible
