    JavaScript is a programming language for the web that enables:

===============================================

Setting Up JavaScript:
    1. Create a JavaScript file with .js extension (e.g., script.js)
    2. Link the JS file to your HTML file using:
       <script src="script.js"></script>
    3. Open the HTML file in a browser to run the code
    4. Use the browser console (F12) to view output and debug

    ✓ Can see results immediately in the console

CHAPTER 3: VARIABLES
===============================================

Three Types of Variable Declarations in JavaScript:

1. var (Old way - avoid using)
   • Scope: Global or Function scope
   • Re-assignable: ✓ YES
   • Re-declarable: ✓ YES
   Example: var name = "John";
   
2. let (Modern - Use for changing values)
   • Scope: Block scope { }
   • Re-assignable: ✓ YES
   • Re-declarable: ✗ NO
   Example: let age = 25;
   
3. const (Modern - Use for constants)
   • Scope: Block scope { }
   • Re-assignable: ✗ NO
   • Re-declarable: ✗ NO
   Example: const PI = 3.14;

Understanding Undefined:
    • Variable is declared: ✓ YES
    • Value is assigned: ✗ NO
    Example:
        let myVar;          // myVar is undefined
        console.log(myVar); // Output: undefined

Variable Naming Conventions:
    
    ✓ CORRECT METHODS:
        • camelCase - let userName;        // ⭐ Most Preferred
        • kebab-case - let user-name;      // Used in CSS
        • PascalCase - let UserName;       // Used for classes
        • Dollar prefix - let $userName;   // Valid in JS
        • Underscore - let _userName;      // Valid in JS
        • Normal - let username;           // Valid but less readable
    
    ✗ INCORRECT METHODS:
        • Starting with number - let 1user;          // ❌ Error
        • Special characters - let user@name;        // ❌ Error (except $ and _)
        • Reserved keywords - let class;             // ❌ Error
        • Spaces - let user name;                    // ❌ Error
    
    Rules:
        → Variable names must start with a letter, $, or _
        → Cannot start with a number
        → Case-sensitive (userName ≠ username)
        → Cannot use reserved keywords (let, const, if, for, etc.)

CHAPTER 4: DATA TYPES
===============================================

JavaScript has TWO main categories of data types:

┌─────────────────────────────────────────────┐
│  I. PRIMITIVE DATA TYPES (Immutable)       │
└─────────────────────────────────────────────┘

1. String
   • Group of characters enclosed in quotes
   • Syntax: "text", 'text', or `text`
   • Example: 
       let name = "John";
       let greeting = 'Hello';
       let template = `Hi ${name}`;  // Template literal

2. Number
   • Numeric values (integers and decimals)
   • Example: 
       let age = 25;
       let price = 99.99;
       let negative = -10;

3. Boolean
   • Logical data type with only two values
   • Values: true or false
   • Example:
       let isStudent = true;
       let isLoggedIn = false;

4. Null
   • Intentional absence of any value
   • Must be assigned explicitly
   • Example: let data = null;

5. Undefined
   • Variable declared but not assigned a value
   • Automatically assigned by JavaScript
   • Example: 
       let x;
       console.log(x); // undefined

┌─────────────────────────────────────────────┐
│  II. NON-PRIMITIVE (REFERENCE) DATA TYPES  │
└─────────────────────────────────────────────┘

1. ARRAYS
   
   Definition:
       • Collection of multiple values stored in a single variable
       • Can hold different data types: strings, numbers, booleans, etc.
       • Values are accessed by index number (starting from 0)
   
   Syntax:
       const myArray = ["Hello", 2, true, null];
   
   Accessing Array Elements:
       console.log(myArray[0]);  // "Hello" (first element)
       console.log(myArray[1]);  // 2 (second element)
   
   Array Property:
       • .length - Returns the total number of elements
       Example: myArray.length; // 4
   
   Common Array Methods:
       
       Adding Elements:
       • push() - Adds element(s) at the END of the array
         Example: myArray.push("new item");
       
       • unshift() - Adds element(s) at the BEGINNING (index 0)
         Example: myArray.unshift("first item");
       
       Removing Elements:
       • pop() - Removes the LAST element
         Example: myArray.pop();
       
       • shift() - Removes the FIRST element (at index 0)
         Example: myArray.shift();
       
       Other Useful Methods:
       • indexOf() - Find the index of an element
       • includes() - Check if element exists
       • slice() - Extract a portion of array
       • splice() - Add/remove elements at specific position

2. OBJECTS
   
   Definition:
       • Collection of key-value pairs (properties)
       • Similar to arrays but uses named keys instead of numeric indexes
       • Each value must have a corresponding key
   
   Syntax:
       const person = {
           name: "Sudalaimani",
           age: 22,
           isStudent: true,
           hobbies: ["coding", "reading"]
       };
   
   Accessing Object Properties:
       
       Method 1 - Dot Notation (Most Common):
           console.log(person.name);  // Output: "Sudalaimani"
           console.log(person.age);   // Output: 22
       
       Method 2 - Bracket Notation:
           console.log(person["name"]);  // Output: "Sudalaimani"
           console.log(person["age"]);   // Output: 22
   
   Adding/Modifying Properties:
       person.city = "Chennai";      // Add new property
       person.age = 23;              // Modify existing property
   
   Deleting Properties:
       delete person.isStudent;

┌─────────────────────────────────────────────┐
│  CHECKING DATA TYPES                        │
└─────────────────────────────────────────────┘

Use typeof operator to check the data type:
    console.log(typeof "Hello");     // "string"
    console.log(typeof 42);          // "number"
    console.log(typeof true);        // "boolean"
    console.log(typeof undefined);   // "undefined"
    console.log(typeof null);        // "object" (known JS quirk)
    console.log(typeof [1,2,3]);     // "object"
    console.log(typeof {name: "x"}); // "object"

CHAPTER 5: TYPE CONVERSION
===============================================

Type conversion (also called type casting) is the process of converting a value from one data type to another.

┌─────────────────────────────────────────────┐
│  CONVERTING TO STRING                       │
└─────────────────────────────────────────────┘

1. Number to String:
   
   Method: String() constructor
   
   Example:
       let value = String(7);
       console.log(value);        // "7"
       console.log(typeof value); // "string"
       
       value = String(4 + 4);
       console.log(value);        // "8"
       console.log(typeof value); // "string"

2. Boolean to String:
   
   Example:
       let value = String(true);
       console.log(value);        // "true"
       console.log(typeof value); // "string"

3. Array to String:
   
   Example:
       let value = String(["Apple", "Orange"]);
       console.log(value);        // "Apple,Orange"
       console.log(typeof value); // "string"

┌─────────────────────────────────────────────┐
│  CONVERTING TO NUMBER                       │
└─────────────────────────────────────────────┘

1. String to Number:
   
   Method: Number() constructor
   
   Example:
       let value = Number("55");
       console.log(value);        // 55
       console.log(typeof value); // "number"
       
       value = Number("Hello");
       console.log(value);        // NaN (Not a Number)
       
       value = Number("5" + "5");
       console.log(value);        // 55
       
       value = Number("5 + 5");
       console.log(value);        // NaN (string expression)

2. Array to Number:
   
   Example:
       let value = Number([1, 2, 3]);
       console.log(value);        // NaN (cannot convert array to number)

┌─────────────────────────────────────────────┐
│  CONVERTING TO BOOLEAN                      │
└─────────────────────────────────────────────┘

Method: Boolean() constructor

Falsy Values (convert to false):
    • false
    • 0 (zero)
    • "" (empty string)
    • null
    • undefined
    • NaN

Truthy Values (convert to true):
    • Any non-zero number (1, 2, -1, etc.)
    • Any non-empty string
    • Arrays (even empty)
    • Objects (even empty)

Examples:
    let value = Boolean();          // false (no value)
    console.log(value);
    
    value = Boolean("Hello");       // true (non-empty string)
    console.log(value);
    
    value = Boolean(0);             // false (zero)
    console.log(value);
    
    value = Boolean(1);             // true (non-zero)
    console.log(value);
    
    value = Boolean(2);             // true (has value)
    console.log(value);
    
    value = Boolean("Hi");          // true (non-empty string)
    console.log(value);
    
    value = Boolean(null);          // false (null value)
    console.log(value);

┌─────────────────────────────────────────────┐
│  CONVERTING TO ARRAY                        │
└─────────────────────────────────────────────┘

String to Array:
   
   Method: Array() constructor
   
   Example:
       let value = Array("Hello");
       console.log(value);        // ["Hello"]
       console.log(typeof value); // "object"

┌─────────────────────────────────────────────┐
│  PARSING NUMBERS                            │
└─────────────────────────────────────────────┘

1. parseInt() - Convert to Integer:
   
   • Parses a string and returns an integer
   • Removes decimal part
   
   Example:
       let value = parseInt(100.4);
       console.log(value);        // 100
       
       value = parseInt("42");
       console.log(value);        // 42
       
       value = parseInt("42.99");
       console.log(value);        // 42

2. parseFloat() - Convert to Float:
   
   • Parses a string and returns a floating-point number
   • Keeps decimal part
   
   Example:
       let value = parseFloat(10.333);
       console.log(value);        // 10.333
       
       value = parseFloat("3.14");
       console.log(value);        // 3.14

Key Differences:
    parseInt()    → Returns whole numbers (integers)
    parseFloat()  → Returns decimal numbers (floats)
    Number()      → Converts entire value, returns NaN if invalid

CHAPTER 6: NUMBERS & MATH OPERATIONS
===============================================

Working with numbers and performing mathematical calculations.

┌─────────────────────────────────────────────┐
│  BASIC ARITHMETIC OPERATORS                 │
└─────────────────────────────────────────────┘

JavaScript supports the following arithmetic operators:

Operator    Description              Example     Result
--------    -----------              -------     ------
   +        Addition                 20 + 10     30
   -        Subtraction              20 - 10     10
   *        Multiplication           20 * 10     200
   /        Division                 20 / 10     2
   %        Modulo (Remainder)       20 % 10     0
   **       Exponentiation           2 ** 3      8

Example Code:
    const numOne = 20;
    const numTwo = 10;
    let value;
    
    value = numOne + numTwo;       // 30
    value = numOne - numTwo;       // 10
    value = numOne * numTwo;       // 200
    value = numOne / numTwo;       // 2
    value = numOne % numTwo;       // 0

┌─────────────────────────────────────────────┐
│  MATH OBJECT                                │
└─────────────────────────────────────────────┘

JavaScript's built-in Math object provides mathematical functions and constants.

1. Math.PI
   • Returns the value of PI (π)
   • Value: 3.141592653589793
   
   Example:
       let value = Math.PI;
       console.log(value);  // 3.141592653589793

2. Math.round()
   • Rounds to the nearest integer
   • .5 and above rounds up, below .5 rounds down
   
   Example:
       let value = Math.round(2.5);   // 3
       value = Math.round(2.1);       // 2
       value = Math.round(2.9);       // 3

3. Math.ceil()
   • Rounds UP to the nearest integer
   • Always rounds to the higher value
   
   Example:
       let value = Math.ceil(2.1);    // 3
       value = Math.ceil(2.9);        // 3

4. Math.floor()
   • Rounds DOWN to the nearest integer
   • Always rounds to the lower value
   
   Example:
       let value = Math.floor(2.1);   // 2
       value = Math.floor(2.9);       // 2

5. Math.sqrt()
   • Returns the square root of a number
   
   Example:
       let value = Math.sqrt(100);    // 10
       value = Math.sqrt(64);         // 8

6. Math.abs()
   • Returns the absolute (positive) value
   • Removes negative sign
   
   Example:
       let value = Math.abs(-3);      // 3
       value = Math.abs(-10);         // 10

7. Math.min()
   • Returns the smallest number from arguments
   
   Example:
       let value = Math.min(1, 2, 3);        // 1
       value = Math.min(10, 5, 20, 3);       // 3

8. Math.max()
   • Returns the largest number from arguments
   
   Example:
       let value = Math.max(1, 3, 45);       // 45
       value = Math.max(10, 5, 20, 3);       // 20

9. Math.random()
   • Returns a random decimal number between 0 (inclusive) and 1 (exclusive)
   • Useful for generating random numbers
   
   Example:
       let value = Math.random();
       console.log(value);  // e.g., 0.12345...
       
       // To get a random number within a range (e.g., 1 to 10)
       value = Math.floor(Math.random() * 10 + 1);
       console.log(value);  // Random integer between 1 and 10

CHAPTER 7: STRINGS & STRING METHODS
===============================================

Strings are used for storing and manipulating text.

┌─────────────────────────────────────────────┐
│  STRING CONCATENATION & APPENDING           │
└─────────────────────────────────────────────┘

1. Concatenation (+)
   • Joining two or more strings together
   
   Example:
       const firstName = "Sudalai";
       const lastName = "Mani";
       let value = firstName + " " + lastName;
       console.log(value);  // "Sudalai Mani"

2. Appending (+=)
   • Adding a string to an existing one
   
   Example:
       let message = "Hello";
       message += " World";
       console.log(message); // "Hello World"

┌─────────────────────────────────────────────┐
│  PROPERTIES & METHODS                       │
└─────────────────────────────────────────────┘

1. length
   • Property that returns the number of characters
   
   Example:
       const text = "Hello";
       console.log(text.length); // 5

2. concat()
   • Method to join strings (alternative to +)
   
   Example:
       const str1 = "Hello";
       const str2 = "World";
       console.log(str1.concat(" ", str2)); // "Hello World"

3. toUpperCase() / toLowerCase()
   • Convert string to upper or lower case
   
   Example:
       const text = "JavaScript";
       console.log(text.toUpperCase()); // "JAVASCRIPT"
       console.log(text.toLowerCase()); // "javascript"

4. indexOf() / lastIndexOf()
   • Find the index of a character or substring
   • indexOf() finds the first occurrence
   • lastIndexOf() finds the last occurrence
   • Returns -1 if not found
   
   Example:
       const str = "hello world";
       console.log(str.indexOf('o'));       // 4 (first 'o')
       console.log(str.lastIndexOf('o'));   // 7 (second 'o')
       console.log(str.indexOf('z'));       // -1

5. charAt()
   • Returns the character at a specific index
   
   Example:
       const str = "Hello";
       console.log(str.charAt(0)); // "H"
       console.log(str.charAt(1)); // "e"

6. substring()
   • Extracts a part of a string between two indexes
   
   Example:
       const str = "JavaScript";
       console.log(str.substring(0, 4)); // "Java"

7. slice()
   • Similar to substring(), but can use negative indexes
   • Negative index starts from the end of the string
   
   Example:
       const str = "JavaScript";
       console.log(str.slice(0, 4));  // "Java"
       console.log(str.slice(-6));    // "Script"

8. split()
   • Splits a string into an array of substrings
   • Takes a separator as an argument
   
   Example:
       const tags = "web,dev,css,js";
       console.log(tags.split(',')); // ["web", "dev", "css", "js"]

9. replace()
   • Replaces a specified value with another value
   • Only replaces the first match by default
   
   Example:
       const str = "Hello World";
       console.log(str.replace("World", "JS")); // "Hello JS"

10. includes()
    • Checks if a string contains a specified substring
    • Returns true or false
    
    Example:
        const str = "Hello World";
        console.log(str.includes("World")); // true
        console.log(str.includes("Moon"));  // false

CHAPTER 8: TEMPLATE STRINGS (TEMPLATE LITERALS)
===============================================

Introduced in ES6, template literals provide an easier way to work with strings, especially for embedding expressions and creating multi-line strings.

┌─────────────────────────────────────────────┐
│  SYNTAX                                     │
└─────────────────────────────────────────────┘

Template literals use backticks (``) instead of single or double quotes.

Example:
    const message = `This is a template literal.`;

┌─────────────────────────────────────────────┐
│  FEATURES & ADVANTAGES                      │
└─────────────────────────────────────────────┘

1. Expression Interpolation
   • Easily embed variables and expressions directly into a string
   • Syntax: ${expression}
   
   Old Way (Concatenation):
       const name = "John";
       const age = 30;
       const message = "My name is " + name + " and I am " + age + " years old.";
   
   New Way (Template Literal):
       const name = "John";
       const age = 30;
       const message = `My name is ${name} and I am ${age} years old.`;

2. Multi-line Strings
   • Create strings that span multiple lines without using `\n`
   
   Old Way:
       const html = '<ul>\n' +
                    '  <li>Item 1</li>\n' +
                    '  <li>Item 2</li>\n' +
                    '</ul>';
   
   New Way:
       const html = `
           <ul>
             <li>Item 1</li>
             <li>Item 2</li>
           </ul>
       `;

3. Tagged Templates (Advanced)
   • Allows you to parse template literals with a function.
   
   Example:
       function myTag(strings, personExp, ageExp) {
           const str0 = strings[0]; // "That "
           const str1 = strings[1]; // " is a "
           const str2 = strings[2]; // "."
           
           const ageStr = ageExp > 99 ? 'centenarian' : 'youngster';
           
           return `${str0}${personExp}${str1}${ageStr}${str2}`;
       }
       
       const person = 'Mike';
       const age = 28;
       const output = myTag`That ${person} is a ${age}.`;
       console.log(output); // "That Mike is a youngster."

CHAPTER 9: ARRAY & ARRAY METHODS
===============================================

Arrays are list-like objects used to store multiple values in a single variable.

┌─────────────────────────────────────────────┐
│  CREATING ARRAYS                            │
└─────────────────────────────────────────────┘

1. Array Literal (Most common)
   const numbers = [1, 2, 3, 4, 5];
   const fruits = ["Apple", "Banana", "Orange"];

2. Array Constructor
   const numbers = new Array(1, 2, 3, 4, 5);

┌─────────────────────────────────────────────┐
│  COMMON ARRAY METHODS                       │
└─────────────────────────────────────────────┘

1. push()
   • Adds one or more elements to the END of an array
   • Returns the new length of the array
   
   Example:
       const fruits = ["Apple", "Banana"];
       fruits.push("Orange");
       console.log(fruits); // ["Apple", "Banana", "Orange"]

2. pop()
   • Removes the LAST element from an array
   • Returns the removed element
   
   Example:
       const fruits = ["Apple", "Banana", "Orange"];
       const removed = fruits.pop();
       console.log(fruits);  // ["Apple", "Banana"]
       console.log(removed); // "Orange"

3. unshift()
   • Adds one or more elements to the BEGINNING of an array
   • Returns the new length of the array
   
   Example:
       const fruits = ["Banana", "Orange"];
       fruits.unshift("Apple");
       console.log(fruits); // ["Apple", "Banana", "Orange"]

4. shift()
   • Removes the FIRST element from an array
   • Returns the removed element
   
   Example:
       const fruits = ["Apple", "Banana", "Orange"];
       const removed = fruits.shift();
       console.log(fruits);  // ["Banana", "Orange"]
       console.log(removed); // "Apple"

5. indexOf()
   • Returns the first index at which a given element can be found
   • Returns -1 if the element is not present
   
   Example:
       const fruits = ["Apple", "Banana", "Orange"];
       console.log(fruits.indexOf("Banana")); // 1
       console.log(fruits.indexOf("Grape"));  // -1

6. includes()
   • Determines whether an array includes a certain value
   • Returns true or false
   
   Example:
       const fruits = ["Apple", "Banana", "Orange"];
       console.log(fruits.includes("Banana")); // true
       console.log(fruits.includes("Grape"));  // false

7. slice()
   • Returns a shallow copy of a portion of an array into a new array
   • Does NOT modify the original array
   
   Example:
       const numbers = [1, 2, 3, 4, 5];
       const subArray = numbers.slice(1, 4); // from index 1 to 3
       console.log(subArray); // [2, 3, 4]
       console.log(numbers);  // [1, 2, 3, 4, 5] (original is unchanged)

8. splice()
   • Changes the contents of an array by removing or replacing existing elements and/or adding new elements
   • MODIFIES the original array
   
   Syntax: splice(start, deleteCount, item1, item2, ...)
   
   Example (Removing):
       const numbers = [1, 2, 3, 4, 5];
       numbers.splice(2, 2); // remove 2 elements starting from index 2
       console.log(numbers); // [1, 2, 5]
   
   Example (Adding):
       const numbers = [1, 2, 5];
       numbers.splice(2, 0, 3, 4); // at index 2, delete 0, add 3 and 4
       console.log(numbers); // [1, 2, 3, 4, 5]

CHAPTER 10: OBJECTS
===============================================

Objects are collections of key-value pairs. They are a fundamental building block in JavaScript.

┌─────────────────────────────────────────────┐
│  OBJECT LITERALS                            │
└─────────────────────────────────────────────┘

The most common way to create an object.

Syntax:
    const person = {
        name: "Sudalaimani",
        age: 22,
        isStudent: true,
        address: {
            city: "Ettaiyapuram",
            street: "East Street"
        },
        hobbies: ["Playing", "Studying"],
        // A function inside an object is called a method
        getFullName: function() {
            return this.name;
        }
    };

Key Characteristics:
    • Reference Type: Objects are not stored directly in variables; the variable holds a reference (or pointer) to the object's location in memory.
    • Mutable: You can change, add, or remove properties after the object is created.

┌─────────────────────────────────────────────┐
│  ACCESSING PROPERTIES                       │
└─────────────────────────────────────────────┘

1. Dot Notation (.)

   • The easiest and most common way.
   • Cannot be used if the key is a number or contains special characters/spaces.
   
   Example:
       console.log(person.name);      // "Sudalaimani"
       console.log(person.address.city); // "Ettaiyapuram"

2. Bracket Notation ([])
   • More versatile.
   • Use when the key is stored in a variable or contains spaces/special characters.
   
   Example:
       console.log(person["age"]);         // 22
       let key = "name";
       console.log(person[key]);           // "Sudalaimani"
       // person."City" would be an error, but person["City"] works.

┌─────────────────────────────────────────────┐
│  MANIPULATING OBJECTS                       │
└─────────────────────────────────────────────┘

1. Adding/Updating Properties:
   person.email = "test@example.com"; // Adds a new property
   person.age = 23;                     // Updates an existing property

2. Calling Methods:
   console.log(person.getFullName());   // "Sudalaimani"

CHAPTER 11: CONDITIONAL STATEMENTS (IF/ELSE)
===============================================

Conditional statements control behavior in JavaScript and determine whether or not pieces of code can run.

┌─────────────────────────────────────────────┐
│  IF...ELSE STATEMENT                        │
└─────────────────────────────────────────────┘

Executes a block of code if a specified condition is true. If the condition is false, another block of code can be executed.

Syntax:
    if (condition) {
        // block of code to be executed if the condition is true
    } else {
        // block of code to be executed if the condition is false
    }

Example:
    let age = 18;
    if (age >= 18) {
        console.log("You are an adult.");
    } else {
        console.log("You are a minor.");
    }

┌─────────────────────────────────────────────┐
│  ELSE IF STATEMENT                          │
└─────────────────────────────────────────────┘

Used to specify a new condition to test, if the first condition is false.

Example:
    const color = "red";
    if (color === "blue") {
        console.log("The color is blue");
    } else if (color === "green") {
        console.log("The color is green");
    } else if (color === "red") {
        console.log("The color is red");
    } else {
        console.log("The color is not blue, green, or red");
    }

┌─────────────────────────────────────────────┐
│  COMPARISON & LOGICAL OPERATORS             │
└─────────────────────────────────────────────┘

Comparison Operators:
    ==      Equal to (value)
    ===     Strictly equal to (value and type)
    !=      Not equal to (value)
    !==     Strictly not equal to (value and type)
    >       Greater than
    <       Less than
    >=      Greater than or equal to
    <=      Less than or equal to

Logical Operators:
    &&      AND (both conditions must be true)
    ||      OR (at least one condition must be true)
    !       NOT (inverts the boolean value)

Example (Logical AND):
    const a = 10;
    const b = 10;
    if (a > 5 && b === 10) {
        console.log("Both conditions are true.");
    }

Example (Logical OR):
    const c = 20;
    const d = 30;
    if (c === 20 || d === 25) {
        console.log("At least one condition is true.");
    }

CHAPTER 12: SWITCH STATEMENT
===============================================

The switch statement is used to perform different actions based on different conditions. It's often a more elegant alternative to a long `if...else if...else` chain.

┌─────────────────────────────────────────────┐
│  SYNTAX                                     │
└─────────────────────────────────────────────┘

    switch(expression) {
        case value1:
            // code block
            break;
        case value2:
            // code block
            break;
        default:
            // code block if no case matches
    }

How it works:
    1. The `expression` is evaluated once.
    2. The value of the expression is compared with the values of each `case`.
    3. If there is a match, the associated block of code is executed.
    4. The `break` keyword stops the execution inside the switch block. Without it, execution would "fall through" to the next case.
    5. The `default` block is executed if no case matches.

Example:
    const color = "red";
    switch(color) {
        case "blue":
            console.log("The color is blue");
            break;
        case "red":
            console.log("The color is red");
            break;
        default:
            console.log("Not a valid color");
    }

Using with Expressions:
    const age = 20;
    switch(true) {
        case age >= 18:
            console.log("Wow, you are an adult");
            break;
        case age < 18:
            console.log("Sorry, you are not an adult");
            break;
        default:
            console.log("Not a valid age");
    }

CHAPTER 13: FUNCTIONS
===============================================

Functions are one of the fundamental building blocks in JavaScript. A function is a reusable set of statements that performs a task or calculates a value.

┌─────────────────────────────────────────────┐
│  FUNCTION DECLARATION (OR STATEMENT)        │
└─────────────────────────────────────────────┘

A function defined with the `function` keyword. These are "hoisted," meaning they can be called before they are defined in the code.

Syntax:
    function functionName(parameter1, parameter2) {
        // code to be executed
        return parameter1 + parameter2;
    }

Example:
    // Calling the function
    let result = greet("Mani");
    console.log(result); // "Hello Mani"

    // Defining the function
    function greet(user) {
        return `Hello ${user}`;
    }

┌─────────────────────────────────────────────┐
│  FUNCTION EXPRESSION                        │
└─────────────────────────────────────────────┘

A function created and assigned to a variable. These are not hoisted and cannot be called before they are defined.

Syntax (Anonymous Function):
    const variableName = function(parameter1, parameter2) {
        // code to be executed
    };

Syntax (Arrow Function - ES6):
    const sum = (a, b) => a + b;

Example:
    // console.log(sum(2, 3)); // Throws an error because it's called before definition
    const sum = (a, b) => a + b;
    console.log(sum(20, 30)); // 50

┌─────────────────────────────────────────────┐
│  PARAMETERS & ARGUMENTS                     │
└─────────────────────────────────────────────┘

    • Parameters are the names listed in the function definition.
    • Arguments are the real values passed to the function when it is called.

Default Parameters (ES6):
You can provide default values for parameters.

Example:
    function add(a, b = 20) {
        return a + b;
    }
    console.log(add(2));      // 22 (uses default b=20)
    console.log(add(2, 300)); // 302 (overwrites default)

CHAPTER 14: DOM (DOCUMENT OBJECT MODEL)
===============================================

What is the DOM?
    • DOM stands for Document Object Model
    • It represents the HTML document as a tree of objects
    • Each HTML element becomes an object that can be manipulated with JavaScript
    • The DOM allows JavaScript to dynamically change HTML content, structure, and styles

┌─────────────────────────────────────────────┐
│  THE DOCUMENT OBJECT                        │
└─────────────────────────────────────────────┘

The `document` object is a built-in JavaScript object that represents the entire HTML page.

Key Point:
    • `document` is a reserved keyword in JavaScript
    • You cannot create a variable named `document`
    • It provides access to all HTML elements and their properties

Example:
    const val = document;
    console.log(val); // Prints the entire HTML document object

┌─────────────────────────────────────────────┐
│  DOCUMENT PROPERTIES                        │
└─────────────────────────────────────────────┘

The document object has many useful properties:

1. document.all
   • Returns an HTMLCollection of all elements in the document
   • Includes every single HTML element
   
   Example:
       console.log(document.all);
       console.log(document.all[0]); // First element (usually <html>)
       console.log(document.all.length); // Total number of elements

2. document.doctype
   • Returns the Document Type Declaration (<!DOCTYPE>)
   • Shows the HTML version being used
   
   Example:
       console.log(document.doctype); // <!DOCTYPE html>

3. document.domain
   • Returns the domain name of the document server
   • Useful for security and cross-origin checks
   
   Example:
       console.log(document.domain); // e.g., "localhost" or "example.com"

4. document.URL
   • Returns the complete URL of the current document
   • Includes protocol, domain, and path
   
   Example:
       console.log(document.URL); // e.g., "http://localhost:5500/index.html"

5. document.body
   • Returns the <body> element of the document
   • Most commonly used for DOM manipulation
   
   Example:
       console.log(document.body); // Prints the entire <body> element

6. Other Useful Properties:
   • document.head - Returns the <head> element
   • document.title - Returns or sets the document's title
   • document.forms - Returns all <form> elements
   • document.images - Returns all <img> elements
   • document.links - Returns all <a> elements with href attribute
   • document.scripts - Returns all <script> elements

┌─────────────────────────────────────────────┐
│  WHY USE THE DOM?                           │
└─────────────────────────────────────────────┘

The DOM enables JavaScript to:
    1. ✅ Create dynamic HTML elements
    2. ✅ Modify existing HTML elements and attributes
    3. ✅ Change CSS styles dynamically
    4. ✅ Add or remove HTML elements from the page
    5. ✅ Create new events and event handlers
    6. ✅ React to existing events (clicks, keypresses, etc.)

┌─────────────────────────────────────────────┐
│  DOM TREE STRUCTURE                         │
└─────────────────────────────────────────────┘

The HTML DOM is structured as a tree of objects:

    Document
       │
       └─── <html>
               │
               ├─── <head>
               │      ├─── <title>
               │      └─── <meta>
               │
               └─── <body>
                      ├─── <div>
                      ├─── <p>
                      └─── <script>

Each node in the tree is an object that can be accessed and modified.

┌─────────────────────────────────────────────┐
│  ACCESSING ELEMENTS (BASICS)                │
└─────────────────────────────────────────────┘

Common methods to select/access HTML elements:

1. getElementById()
   • Selects an element by its ID attribute
   • Returns a single element
   
   Example:
       const element = document.getElementById('myId');

2. getElementsByClassName()
   • Selects all elements with a specific class name
   • Returns an HTMLCollection (array-like)
   
   Example:
       const elements = document.getElementsByClassName('myClass');

3. getElementsByTagName()
   • Selects all elements with a specific tag name
   • Returns an HTMLCollection
   
   Example:
       const paragraphs = document.getElementsByTagName('p');

4. querySelector()
   • Selects the first element that matches a CSS selector
   • Returns a single element
   
   Example:
       const element = document.querySelector('.myClass');

5. querySelectorAll()
   • Selects all elements that match a CSS selector
   • Returns a NodeList
   
   Example:
       const elements = document.querySelectorAll('div.container');

┌─────────────────────────────────────────────┐
│  PRACTICAL EXAMPLE                          │
└─────────────────────────────────────────────┘

Basic DOM exploration:
    const val = document;
    
    console.log(val.all);      // All HTML elements
    console.log(val.doctype);  // Document type
    console.log(val.domain);   // Domain name
    console.log(val.URL);      // Complete URL
    console.log(val.body);     // Body element

    • Handle user events (clicks, inputs, etc.)
