================================================================================
                    TO-DO APP - FEATURE DOCUMENTATION
================================================================================

PROJECT OVERVIEW:
-----------------
This is a fully functional To-Do application built with vanilla JavaScript that 
allows users to add, remove, search, and persist tasks using Local Storage.

================================================================================
CORE FEATURES IMPLEMENTED:
================================================================================

1. DOM ELEMENT SELECTION
   ----------------------
   - Task Form (#task-form): Main form for adding new tasks
   - Clear Button (.clear-tasks): Removes all tasks at once
   - List Container (.collection): UL element that holds all task items
   - Input Field (#task): Text input where users type tasks
   - Filter Input (#search): Search field for filtering tasks

2. EVENT MANAGEMENT SYSTEM
   ------------------------
   Created a centralized loadAllEvent() function that registers 5 event listeners:
   
   a) DOMContentLoaded Event
      - Loads saved tasks from localStorage when page loads
      - Ensures tasks persist across browser sessions
   
   b) Form Submit Event
      - Adds new tasks when user submits the form
      - Prevents page refresh with e.preventDefault()
   
   c) Clear Button Click Event
      - Removes all tasks from both DOM and localStorage
   
   d) List Container Click Event (Event Delegation)
      - Listens for clicks on dynamically created delete icons
      - Removes individual tasks
   
   e) Filter Input Keyup Event
      - Filters/searches tasks in real-time as user types

3. TASK LOADING FROM LOCAL STORAGE
   --------------------------------
   Function: loadTask(e)
   
   - Runs on DOMContentLoaded event
   - Retrieves tasks array from localStorage
   - Creates DOM elements (li + delete icon) for each stored task
   - Appends all tasks to the list container
   - Handles empty localStorage gracefully

4. ADD TASK FUNCTIONALITY
   -----------------------
   Function: addTask(e)
   
   Features:
   - Input validation (prevents empty task submissions)
   - Creates list item with proper class names
   - Adds delete icon (Font Awesome) to each task
   - Appends task to DOM
   - Saves task to localStorage via storeTask()
   - Clears input field after submission

5. FILTER/SEARCH FEATURE
   ----------------------
   Function: filterTasks(e)
   
   - Real-time search as user types
   - Case-insensitive search using toLowerCase()
   - Uses indexOf() to check if search query exists in task text
   - Shows matching tasks (display: block)
   - Hides non-matching tasks (display: none)
   - Works on all tasks in the list

6. REMOVE INDIVIDUAL TASK
   -----------------------
   Function: removeTask(e)
   
   - Uses EVENT DELEGATION technique on list container
   - Detects clicks on delete icons (checks for "delete-item" class)
   - Shows confirmation dialog before deletion
   - Removes task from DOM using .remove()
   - Calls removeTaskFromLocalStorage() to update storage
   - DOM traversal: e.target (icon) → parentElement (link) → parentElement (li)

7. CLEAR ALL TASKS
   ----------------
   Function: clearTask()
   
   - Converts HTMLCollection to Array using Array.from()
   - Uses forEach() to remove each task individually
   - More efficient than innerHTML = ""
   - Calls clearAllTaskFromLocalStorage() to clear storage
   - Removes all tasks from both UI and persistence layer

8. LOCAL STORAGE INTEGRATION
   --------------------------
   Three dedicated functions for localStorage management:
   
   a) storeTask(providedTask)
      - Retrieves existing tasks array from localStorage
      - Adds new task to the array
      - Saves updated array back to localStorage
      - Uses JSON.stringify() for storage
   
   b) removeTaskFromLocalStorage(taskToRemove)
      - Retrieves tasks array from localStorage
      - Loops through to find matching task by text
      - Uses splice() to remove task from array
      - Updates localStorage with modified array
      
      **ISSUE PRESENT**: 
      - localStorage.setItem() is inside forEach loop (line 130)
      - Should be moved outside for efficiency
      - innerText may include delete icon text
      - Should use textContent.trim() instead
   
   c) clearAllTaskFromLocalStorage()
      - Removes entire "tasks" key from localStorage
      - Called when clearing all tasks

//Filler Tasks Function :-
function filterTasks(e) {
    //Getting the input field:-
    const filterTask = e.target.value.toLowerCase();

    //Getting the list collection :-
    document.querySelectorAll(".collection-item").forEach((taskToFilter) => {
        console.log(taskToFilter);
        const item = taskToFilter.innerText.toLowerCase();
        if (item.indexOf(filterTask) != -1) {
            taskToFilter.style.display = "block";
        } else {
            taskToFilter.style.display = "none";
        }
    })
}

//Add Task Function :-
function addTask(e) {
    e.preventDefault();
    //Condition if the user clicks the task with an empty data (task).
    if (inputField.value === "") {
        alert("Enter a valid task");
    }
    else {
        //Creating the LI :-
        const li = document.createElement("li");
        li.className = "collection-item";
        li.innerText = inputField.value;
        //Creating the Link :-
        const link = document.createElement("a");
        link.href = "#";
        link.className = "delete-item secondary-content";
        link.innerHTML = '<i class="fa fa-remove"></i>';
        //Appending the Link to the LI :-
        li.appendChild(link);
        //Append the Li to the list container  :-
        listContainer.appendChild(li);
        //Store the Task :-
        storeTask(inputField.value);
        inputField.value = "";
    }
};

//Clear Task Function :-
function clearTask() {
    // listContainer.innerHTML = "";
    const listItem = Array.from(listContainer.children);
    console.log(listItem);
    listItem.forEach((element) => element.remove());
    clearAllTaskFromLocalStorage();
};

//Remove Task Function :-
function removeTask(e) {
    console.log(e.target.parentElement.classList.contains("delete-item"));
    if (e.target.parentElement.classList.contains("delete-item")) {
        if (confirm("Are you sure to remove the task ?")) {
            e.target.parentElement.parentElement.remove();
        }
        removeTaskFromLocalStorage(e.target.parentElement.parentElement);
    }
};

//Remove Task from the local storage :-
function removeTaskFromLocalStorage(taskToRemove) {
    let taskContainer;
    if (localStorage.getItem("tasks") === null) {
        taskContainer = [];
    }
    else {
        taskContainer = JSON.parse(localStorage.getItem("tasks"));
    }
    taskContainer.forEach((task, taskIndex) => {
        console.log("Task", task);
        console.log("Task index", taskIndex);
        if (taskToRemove.innerText === task) {
            taskContainer.splice(taskIndex, 1);
        }
        //Updating the local storage :-
        localStorage.setItem("tasks", JSON.stringify(taskContainer));
    })
}

//Clear All task from the local storage:-
function clearAllTaskFromLocalStorage() {
    localStorage.removeItem("tasks");
}

//Local Storage :-
function storeTask(providedTask) {
    let taskContainer = [];
    if (localStorage.getItem("tasks") === null) {
        taskContainer = [];
    } else {
        taskContainer = JSON.parse(localStorage.getItem("tasks"));
    }
    taskContainer.push(providedTask);
    localStorage.setItem("tasks", JSON.stringify(taskContainer));
}
