Links and Images

Learn how to add links and images to your HTML page

Topics to Cover:

1. Links (<a> tag)

  • External Link
  • Internal Link
  • Anchor/Jump Link
  • Email Link
  • Phone Link

2. Link Attributes

  • href - URL destination
  • target - Where to open (_blank, _self, _parent, _top)
  • title - Tooltip text
  • rel - Relationship (e.g., noopener)

3. Images (<img> tag)

Basic Image Syntax:

<img src="image.jpg" alt="Description" width="300" height="200">

4. Image Attributes

  • src - Image source/path
  • alt - Alternative text (important for accessibility)
  • width - Image width
  • height - Image height
  • title - Tooltip text

5. Image as Link

<a href="url"><img src="image.jpg" alt="Description"></a>
