# FrontEnd Projects

Complete collection of HTML and JavaScript applications demonstrating practical development skills from fundamentals to advanced concepts.

## Structure

```

│   ├── 3-Restaurant-Menu/        # Restaurant website with menu & reservation
│   ├── 4-Product-Listing/        # E-commerce product listing page
│   ├── 5-Landing-Page/           # SaaS landing page with pricing
│   ├── 6-Event-Registration-Form/ # Comprehensive event registration
│   ├── 7-Documentation-Page/     # Technical documentation with sidebar

    ├── BookManagementApp/        # OOP, LocalStorage CRUD, ES6 classes
    ├── CharacterValidator/       # Real-time input validation
```

## Projects Overview

### HTML Projects

#### 1. Personal Portfolio
**Focus:** Semantic HTML, Forms, Navigation  
**Features:** About section, skills showcase, featured projects, contact form  
**Concepts:** Semantic elements, form validation, links (internal/external/email/phone)

#### 2. Blog Page
**Focus:** Article Structure, Metadata, Sidebar  
**Features:** Multiple articles, publication dates, categories, newsletter signup  
**Concepts:** `<article>`, `<time>`, `<figure>`, `<aside>`, `<blockquote>`, code snippets

#### 3. Restaurant Menu
**Focus:** Tables, Description Lists, Forms  
**Features:** Menu by categories, hours table, reservation form, contact info  
**Concepts:** `<dl>`, `<dt>`, `<dd>`, tables, date/time inputs, `<address>`

#### 4. Product Listing
**Focus:** Forms, Tables, Product Cards  
**Features:** 6 products with specs, ratings, pricing, testimonials  
**Concepts:** Radio buttons, checkboxes, specification tables, pricing markup

#### 5. Landing Page
**Focus:** Pricing Tables, Complex Forms, CTA  
**Features:** Features section, pricing comparison, testimonials, FAQ, signup  
**Concepts:** Complex tables with colspan/rowspan, comprehensive forms, CTAs

#### 6. Event Registration Form
**Focus:** All Form Elements, Validation  
**Features:** Multi-section registration with all HTML5 input types  
**Concepts:** All input types, fieldsets, pattern validation, required fields, accessibility

#### 7. Documentation Page
**Focus:** Navigation, Code Examples, Reference  
**Features:** Sidebar TOC, multiple sections, code blocks, syntax tables  
**Concepts:** Nested navigation, anchor links, `<pre>`, `<code>`, definition lists

#### 8. Online Resume/CV
**Focus:** Professional Structure, Complete Profile  
**Features:** Skills, experience, education, certifications, projects  
**Concepts:** Heading hierarchy, `<time>`, tables, proper document structure

### JavaScript Projects

#### BookManagementApp
**Tech:** ES6 Classes, LocalStorage, OOP  
**Features:** Full CRUD, 191 lines, static methods, persistence  
**Skills:** Object-oriented design, data persistence

#### CharacterValidator
**Tech:** Real-time validation, RegEx  
**Features:** Live input checking, character rules  
**Skills:** Input validation, pattern matching

#### ColorPicker
**Tech:** Vanilla JS, Clipboard API  
**Features:** Random RGB/Hex generation, copy-to-clipboard  
**Skills:** Color algorithms, browser APIs

#### CRUD_Application_Using_API
**Tech:** Async/Await, Fetch API, ES6 Modules  
**Features:** Full CRUD with inline editing, 270 lines, event delegation  
**Skills:** Modern async patterns, RESTful operations, dynamic UI updates

#### SimpleCounterApp
**Tech:** DOM manipulation, state management  
**Features:** Increment/decrement/reset  
**Skills:** Basic state handling, event listeners

#### To-do_App
**Tech:** LocalStorage, Event delegation  
**Features:** Add/edit/delete, search, filter, 290 lines  
**Skills:** Advanced DOM, data filtering, persistence

#### ToDoUsingAPI
**Tech:** Fetch API, REST, ES6 Modules  
**Features:** CRUD with MockAPI, modular architecture  
**Skills:** API integration, async operations, code organization
