📚 Table Structure Components

<table>

The main container element that holds all table content. Required for creating any HTML table.

<caption>

Provides a title or description for the table. Improves accessibility and context for users.

<thead>

Contains header rows with column titles. Groups header content semantically.

<tbody>

Contains the main data rows of the table. Groups body content semantically.

<tfoot>

Contains footer rows like totals or summary information. Groups footer content.

<tr>

Table Row - defines a row of cells. Can contain <th> or <td> elements.

<th>

Table Header cell - bold and centered by default. Used for column or row headers.

<td>

Table Data cell - contains the actual data. Regular text alignment and weight.

💻 Complete HTML Structure

Here's the complete HTML code for creating the employee table shown above:

<table> <!-- Table caption provides context --> <caption>Company Employee Records - Q1 2026</caption> <!-- Table header section --> <thead> <tr> <th>Employee ID</th> <th>Full Name</th> <th>Department</th> <th>Salary</th> </tr> </thead> <!-- Table body with data rows --> <tbody> <tr> <td>EMP001</td> <td>John Smith</td> <td>Engineering</td> <td>$85,000</td> </tr> <tr> <td>EMP002</td> <td>Sarah Johnson</td> <td>Marketing</td> <td>$72,000</td> </tr> <tr> <td>EMP003</td> <td>Michael Chen</td> <td>Design</td> <td>$78,000</td> </tr> <tr> <td>EMP004</td> <td>Emily Davis</td> <td>Sales</td> <td>$68,000</td> </tr> <tr> <td>EMP005</td> <td>David Martinez</td> <td>Engineering</td> <td>$92,000</td> </tr> </tbody> <!-- Table footer with summary --> <tfoot> <tr> <td colspan="3">Total Employees: 5</td> <td>$395,000</td> </tr> </tfoot> </table>
Note: The colspan="3" attribute in the footer makes the first cell span across 3 columns, allowing us to merge cells horizontally.

✅ Table Best Practices

  • Always use <caption>: Provides context and improves accessibility
  • Separate structure with <thead>, <tbody>, <tfoot>: Makes tables semantically clear
  • Use <th> for headers: Screen readers use these to help users navigate
  • Keep tables simple: Avoid using tables for layout purposes (use CSS Grid/Flexbox instead)
  • Add scope attribute: Use scope="col" or scope="row" on <th> elements for better accessibility
  • Use border-collapse: Set to "collapse" for cleaner borders
  • Make responsive: Wrap tables in a container with overflow-x: auto
  • Provide summary: Use <tfoot> for totals or summaries when appropriate
