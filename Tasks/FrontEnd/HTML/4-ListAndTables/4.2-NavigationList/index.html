🧭 Task 4.2: Navigation Lists

Building navigation menus using semantic HTML lists

1. Header Navigation (Horizontal)

The top navigation bar uses an unordered list styled horizontally with Flexbox. This is the most common navigation pattern for website headers.

✨ Semantic HTML

Uses <nav> and <ul> for proper structure

📱 Responsive

Adapts to mobile with vertical stacking

🎯 Active State

Highlights current page location

⚡ Sticky Position

Stays at top when scrolling

<!-- Header Navigation (Horizontal) --> <nav class="header-nav"> <ul> <li><a href="#home" class="active">Home</a></li> <li><a href="#about">About</a></li> <li><a href="#services">Services</a></li> <li><a href="#portfolio">Portfolio</a></li> <li><a href="#contact">Contact</a></li> </ul> </nav> /* CSS for Horizontal Layout */ .header-nav ul { display: flex; /* Flexbox for horizontal layout */ justify-content: center; /* Center alignment */ list-style: none; /* Remove bullets */ }

2. Sidebar Navigation (Vertical)

The sidebar navigation on the left uses a vertical list, perfect for documentation, dashboards, or admin panels. Notice how it's sticky and follows you as you scroll!

📍 Sticky Positioning

Remains visible while scrolling

🎨 Hover Effects

Visual feedback on interaction

🔍 Clear Hierarchy

Easy to scan and navigate

♿ Accessible

Keyboard and screen reader friendly

<!-- Sidebar Navigation (Vertical) --> <aside class="sidebar-nav"> <h3>Documentation</h3> <ul> <li><a href="#intro" class="active">Introduction</a></li> <li><a href="#getting-started">Getting Started</a></li> <li><a href="#installation">Installation</a></li> <li><a href="#configuration">Configuration</a></li> <li><a href="#examples">Examples</a></li> </ul> </aside> /* CSS for Vertical Layout */ .sidebar-nav ul { list-style: none; } .sidebar-nav li { margin: 8px 0; } .sidebar-nav a { display: block; /* Full-width clickable area */ padding: 12px 15px; }

3. Footer Links Section

The footer below demonstrates how to organize multiple navigation lists in a grid layout. Each column contains a categorized list of links, common in website footers.

<!-- Footer Navigation --> <footer class="footer-nav"> <div class="footer-content"> <!-- Company Section --> <div class="footer-section"> <h4>Company</h4> <ul> <li><a href="#">About Us</a></li> <li><a href="#">Careers</a></li> <li><a href="#">Press</a></li> </ul> </div> <!-- Resources Section --> <div class="footer-section"> <h4>Resources</h4> <ul> <li><a href="#">Documentation</a></li> <li><a href="#">Blog</a></li> <li><a href="#">Tutorials</a></li> </ul> </div> </div> </footer>

✅ Navigation Best Practices

  • Use semantic HTML: Always use <nav> for navigation sections
  • Lists for structure: Build navigation with <ul> and <li> elements
  • Indicate current page: Use "active" class or aria-current attribute
  • Keyboard accessible: Ensure tab navigation works properly
  • Responsive design: Adapt navigation for mobile (hamburger menu, vertical stack)
  • Clear labels: Use descriptive link text, avoid "Click here"
  • Visual feedback: Provide hover and focus states
  • Consistent placement: Keep navigation in expected locations
