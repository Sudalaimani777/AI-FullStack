# HTML Learning Guide

Complete structured guide to learn HTML from basics to advanced concepts.

## Learning Path Overview

This folder contains 10 comprehensive modules to master HTML:

### 1. **1-Basics** - HTML Document Structure
- DOCTYPE Declaration
- HTML Tag Structure
- Head and Body Tags
- Headings and Paragraphs
- Basic Attributes

**What You'll Learn:** The foundation of every HTML document.

---

### 2. **2-Text-Formatting** - Text Formatting & Styling
- Bold, Italic, Underline
- Strong (semantic), Emphasis (semantic)
- Strikethrough, Highlight, Small
- Subscript and Superscript

**What You'll Learn:** How to format text meaningfully.

---

### 3. **3-Lists** - Different Types of Lists
- Unordered Lists (Bullets)
- Ordered Lists (Numbered)
- Description Lists
- Nested Lists

**What You'll Learn:** How to structure list-based content.

---

### 4. **4-Links-Images** - Links and Images
- Hyperlinks (External, Internal, Anchors)
- Email and Phone Links
- Image Tags and Attributes
- Image as Links
- Accessibility for Images

**What You'll Learn:** How to connect pages and display visual content.

---

### 5. **5-Tables** - Data Tables
- Basic Table Structure (table, tr, td, th)
- Table Headers, Body, Footer
- Table Captions
- Merged Cells (colspan, rowspan)

**What You'll Learn:** How to organize tabular data effectively.

---

### 6. **6-Forms** - Interactive Forms
- Form Elements (input, textarea, select)
- Input Types (text, email, password, date, etc.)
- Form Validation Attributes
- Labels and Form Organization

**What You'll Learn:** How to collect user input and data.

---

### 7. **7-Semantic-HTML** - Semantic HTML5 Elements
- Header, Navigation, Main, Footer
- Article, Section, Aside
- Figure, FigCaption, Time
- SEO Benefits
- Accessibility Benefits

**What You'll Learn:** How to write meaningful, modern HTML.

---

### 8. **8-Meta-Tags** - Head Section & Meta Tags
- Character Encoding
- Viewport (Responsive Design)
- SEO Meta Tags
- Open Graph (Social Media)
- Title Tags

**What You'll Learn:** How to optimize metadata for browsers and search engines.

---

### 9. **9-Accessibility** - Inclusive Web Design
- Semantic HTML for Accessibility
- Alt Text for Images
- Heading Hierarchy
- Form Labels
- ARIA (Accessible Rich Internet Applications)
- Keyboard Navigation
- Color Contrast

**What You'll Learn:** How to make websites accessible to everyone.

---

### 10. **10-Projects** - Real-World Projects
- Personal Portfolio Website
- Blog Page
- Restaurant Menu
- Product Listing Page
- Landing Page
- Event Registration Form
- Documentation Page
- Online Resume/CV

**What You'll Learn:** Apply all concepts to build real projects.

---

## How to Use This Guide

### Study Structure:
1. Open each folder's `index.html` file
2. Read the concepts and examples
3. Try implementing the examples in the marked "Practice Here" section
4. Create variations and experiment

### Progressive Learning:
- Start with **1-Basics** and progress sequentially
- Each module builds on previous knowledge
- Don't skip modules

### Practice Tips:
- Type code manually (don't copy-paste)
- Experiment with different HTML tags
- Validate your HTML using [HTML Validator](https://validator.w3.org/)
- Use browser DevTools to inspect elements (Right-click → Inspect)

### Key Principles to Remember:
1. **Semantic HTML** - Use meaningful tags
2. **Accessibility First** - Write for everyone
3. **Proper Hierarchy** - Headings in logical order
4. **Alt Text** - Always describe images
5. **Clean Code** - Comment and indent properly

## Common HTML Tags Reference

### Document Structure
```
<html>, <head>, <body>, <meta>, <title>
```

### Text Content
```
<h1>-<h6>, <p>, <br>, <hr>, <div>, <span>
```

### Text Formatting
```
<strong>, <em>, <b>, <i>, <u>, <del>, <mark>
```

### Lists
```
<ul>, <ol>, <li>, <dl>, <dt>, <dd>
```

### Links & Media
```
<a>, <img>, <video>, <audio>, <source>
```

### Tables
```
<table>, <tr>, <td>, <th>, <thead>, <tbody>, <tfoot>
```

### Forms
```
<form>, <input>, <textarea>, <select>, <button>, <label>
```

### Semantic
```
<header>, <nav>, <main>, <article>, <section>, <aside>, <footer>
```
