Meta Tags in HTML

Learn about important meta tags in the head section

Topics to Cover:

1. Character Encoding

<meta charset="UTF-8">

Specifies the character encoding for the document

2. Viewport (Responsive Design)

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Makes page responsive on mobile devices

3. SEO Meta Tags

  • description: Page description (50-160 characters)
  • keywords: Relevant keywords (separated by comma)
  • author: Author name

4. Social Media Meta Tags (Open Graph)

  • <meta property="og:title">
  • <meta property="og:description">
  • <meta property="og:image">
  • <meta property="og:url">

5. Other Important Meta Tags

  • theme-color: Browser toolbar color
  • robots: Search engine crawler instructions
  • language: Page language
  • refresh: Auto-refresh page

6. Title Tag

<title>Page Title - Your Site</title>

Displayed in browser tab and search results

7. Complete Head Example

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Page description">
    <meta name="keywords" content="keywords">
    <meta name="author" content="Author">
    <title>Page Title</title>
    <link rel="stylesheet" href="style.css">
</head>
