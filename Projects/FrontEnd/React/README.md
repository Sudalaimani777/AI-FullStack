## 🛠️ General Environment & Tooling Setup

Each project directory inside this hub is an independent, self-contained project configured with **Vite** and **React 19**.

### Quickstart Execution Steps:
1. **Navigate to any target project**:
   ```bash
   cd Projects/FrontEnd/React/<PROJECT_FOLDER>
   ```

2. **Install project dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Build production bundle**:
   ```bash
   npm run build
   ```
