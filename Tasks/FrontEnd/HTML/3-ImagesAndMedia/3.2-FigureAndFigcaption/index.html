🖼️ Task 3.2: Figure and Figcaption

Semantic HTML5 elements for images with captions

📚 What are <figure> and <figcaption>?

The <figure> element represents self-contained content, like images, diagrams, or code snippets. The <figcaption> provides a caption or legend for that content. This semantic approach improves accessibility, SEO, and code readability.

1. Basic Figure with Single Image

A simple example showing an image with a descriptive caption. This is the most common use case.

<figure> <img src="landscape.jpg" alt="Mountain landscape"> <figcaption>Figure 1: A serene mountain landscape</figcaption> </figure>

2. Figure with Detailed Caption

Captions can contain more detailed information, credits, or source information.

<figure> <img src="sunset.jpg" alt="Sunset over ocean"> <figcaption> Figure 2: Spectacular sunset over the Pacific Ocean... Photo by Nature Photographer (2024) </figcaption> </figure>

3. Figure with Technical Content

Figures aren't just for images! They can contain diagrams, charts, or code snippets.

<figure> <pre><code> <div class="container"> <h1>Hello World</h1> </div> </code></pre> <figcaption>Figure 3: HTML structure example</figcaption> </figure>

4. Figure with Multiple Related Images

A single figure can contain multiple related images that share a common caption.

<figure> <img src="spring.jpg" alt="Spring landscape"> <img src="summer.jpg" alt="Summer landscape"> <img src="autumn.jpg" alt="Autumn landscape"> <img src="winter.jpg" alt="Winter landscape"> <figcaption>Figure 4: The four seasons</figcaption> </figure>

✨ Benefits of Using <figure> and <figcaption>

  • Semantic HTML: Clearly indicates the relationship between image and caption
  • Accessibility: Screen readers understand the content structure better
  • SEO: Search engines recognize and index captions, improving discoverability
  • Styling: Easier to style images and captions together as a unit
  • Flexibility: Can contain images, diagrams, code, quotes, or other content
  • Professional: Standard practice in modern web development
  • Maintenance: Easier to update and maintain related content

💡 Best Practices

✅ Always use <figcaption> inside <figure>
✅ Keep captions concise and descriptive
✅ Include proper alt text on images even when using figcaption
✅ Use for self-contained content that could be moved without affecting the main flow
✅ Number figures for easy reference (Figure 1, Figure 2, etc.)
❌ Don't use figure for decorative images that don't need captions
