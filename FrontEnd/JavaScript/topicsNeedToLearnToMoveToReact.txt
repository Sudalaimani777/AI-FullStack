1. ADVANCED ARRAY METHODS - map(), filter(), reduce()
─────────────────────────────────────────────────────
   Priority: ⭐⭐⭐⭐⭐ (CRITICAL for React)
   Status: ❌ NOT FOUND in your codebase
   
   You have basic array methods but MISSING these essential ones:
   
   ├── map()         → Transform arrays (MOST IMPORTANT for React)
   │   Example: const doubled = numbers.map(num => num * 2);
   │   React Use: {items.map(item => <Item key={item.id} />)}
   │
   ├── filter()      → Filter data based on conditions
   │   Example: const adults = users.filter(user => user.age >= 18);
   │   React Use: Filtering state, search functionality
   │
   ├── reduce()      → Aggregate/combine array values
   │   Example: const total = prices.reduce((sum, price) => sum + price, 0);
   │   React Use: Calculating totals, complex state transformations
   │
   ├── find()        → Find first matching element
   │   Example: const user = users.find(u => u.id === 5);
   │
   ├── findIndex()   → Find index of first match
   │   Example: const index = users.findIndex(u => u.id === 5);
   │
   ├── some()        → Check if any element passes test
   │   Example: const hasAdmin = users.some(u => u.role === 'admin');
   │
   └── every()       → Check if all elements pass test
       Example: const allAdults = users.every(u => u.age >= 18);

   Why Critical for React:
   - React renders lists using map() - you'll use it CONSTANTLY
   - filter() is essential for managing state updates
   - reduce() helps with complex state transformations

   📁 Create folder: Topics/9-ArrayMethods/AdvancedMethods/

   Priority: ⭐⭐⭐⭐⭐ (CRITICAL for React)
   Status: ❌ NOT FOUND in your codebase
   
   Topics to Cover:
   ├── Object Destructuring
   │   ├── Basic: const { name, age } = person;
   │   ├── Renaming: const { name: fullName } = person;
   │   └── Default values: const { name = "Unknown" } = person;
   │
   ├── Array Destructuring
   │   ├── Basic: const [first, second] = array;
   │   ├── Skipping: const [, second] = array;
   │   └── Rest: const [first, ...rest] = array;
   │
   └── Nested Destructuring
       └── const { address: { city } } = person;

   Why Critical for React:
   - React props: const MyComponent = ({ name, age }) => { }
   - useState: const [count, setCount] = useState(0);
   - Makes code cleaner and more readable

3. SPREAD & REST OPERATORS (...)
────────────────────────────────
   Priority: ⭐⭐⭐⭐⭐ (CRITICAL for React)
   Status: ❌ NOT FOUND in your codebase
   
   Topics to Cover:
   ├── Spread Operator (...)
   │   ├── Copy arrays: const copy = [...originalArray];
   │   ├── Merge arrays: const merged = [...arr1, ...arr2];
   │   ├── Copy objects: const copy = {...originalObject};
   │   ├── Merge objects: const merged = {...obj1, ...obj2};
   │   └── Add to state: setState([...prevState, newItem]);
   │
   └── Rest Parameters
       ├── Function params: function sum(...numbers) { }
       └── Destructuring: const { a, ...rest } = obj;

   Why Critical for React:
   - State updates: setItems([...items, newItem])
   - Never mutate state directly - spread creates copies
   - Passing props: <Component {...props} />
