HTML Forms

Learn how to create interactive forms

Topics to Cover:

1. Form Container

<form action="submit.php" method="POST"> ... </form>

2. Form Elements

  • <input> - Input fields (text, email, password, number, date, etc.)
  • <textarea> - Multi-line text input
  • <select> - Dropdown lists
  • <option> - Dropdown items
  • <button> - Clickable button
  • <label> - Label for form fields
  • <fieldset> - Group related fields
  • <legend> - Legend for fieldset

3. Input Types

  • text - Single-line text
  • email - Email address
  • password - Hidden password
  • number - Numeric input
  • date - Date picker
  • checkbox - Multiple selections
  • radio - Single selection
  • file - File upload
  • submit - Submit button
  • reset - Reset form

5. Form Attributes

  • action - Where to send form data
  • method - How to send (GET or POST)
  • name - Form name
  • required - Make field mandatory
  • placeholder - Hint text
  • disabled - Disable field
