The HTML tag is used to provide metadata (data about the HTML document) that is not displayed on the page itself but is machine-parsable by browsers, search engines, and other web services

Metadata is information about the webpage such as its description, keywords, author, and character set. Meta tags are placed inside the section of an HTML document.

Commonly used meta tags include:

  • charset: Specifies the character encoding for the HTML document. Example: <meta charset="UTF-8">
  • viewport: Controls the layout on mobile browsers. Example: <meta name="viewport" content="width=device-width, initial-scale=1.0">
  • description: Provides a brief summary of the webpage's content. Example: <meta name="description" content="This is a sample webpage">
  • keywords: Lists keywords relevant to the webpage for search engines. Example: <meta name="keywords" content="HTML, CSS, JavaScript">
  • author: Specifies the author of the document. Example: <meta name="author" content="John Doe">
