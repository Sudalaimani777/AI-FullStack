=== MODERN JAVASCRIPT PATTERNS (ES6+) ===

This folder covers three essential modern JavaScript patterns that make code cleaner and safer.


1. OPTIONAL CHAINING (?.)
========================

What is it?
- A safe way to access nested object properties without checking if each level exists
- Prevents errors when properties are undefined or null
- Uses the ?. operator

Syntax:
  object?.property?.nestedProperty

Why use it?
- Avoids "Cannot read property of undefined" errors
- Much cleaner than checking each level with && operators
- Works with objects, arrays, and function calls

Examples:

  WITHOUT Optional Chaining:
  const city = user && user.address && user.address.city;

  WITH Optional Chaining:
  const city = user?.address?.city;

  With Arrays:
  const firstUserName = users?.[0]?.name;

  With Functions:
  const getUserName = (user) => user?.name;

Key Benefits:
✓ Code is more readable and concise
✓ Prevents runtime errors
✓ Returns undefined if any level is missing


2. NULLISH COALESCING (??)
==========================

What is it?
- An operator that provides a default value
- Returns the RIGHT side only if LEFT side is null or undefined
- Does NOT treat 0, false, or empty string as nullish

Syntax:
  leftExpr ?? rightExpr

Why use it?
- Better than || operator for providing default values
- The || operator treats 0, false, "" as falsy (often wrong!)
- ?? only cares about null/undefined (the true "nullish" values)

Examples:

  const name = user.name ?? "Unknown";  // Returns "Unknown" only if name is null/undefined
  const count = 0 ?? 10;                 // Returns 0 (not 10!), because 0 is not nullish
  const active = false ?? true;          // Returns false (not true!), because false is not nullish

Important Notes:
- Cannot use ?? directly with || or && without parentheses
- Wrap mixed operators in parentheses:
  const result = (user || undefined) ?? "Default";

Difference from ||:

  Using || (treats many values as "falsy"):
  const count = 0 || 10;  // Result: 10 (WRONG - 0 is valid!)

  Using ?? (only treats null/undefined as "nullish"):
  const count = 0 ?? 10;  // Result: 0 (CORRECT!)


3. TERNARY OPERATOR & SHORT CIRCUIT LOGIC
===========================================

What is it?
- Ways to control code flow using logical operators
- Short circuit: JavaScript stops evaluating as soon as it knows the result

A. LOGICAL AND (&&):
  - If first value is FALSE, the second is NOT evaluated
  - If first value is TRUE, returns the second value
  
  Syntax: condition && expressionToExecute

  Example:
  let isAdmin = true;
  let message = isAdmin && "Welcome Admin!";  // "Welcome Admin!"
  
  let isGuest = false;
  let message = isGuest && "Welcome Guest!";  // false (doesn't evaluate right side)

B. LOGICAL OR (||):
  - If first value is TRUE, the second is NOT evaluated
  - If first value is FALSE, returns the second value
  
  Syntax: condition || defaultValue

  Example:
  let userName = null;
  let name = userName || "Guest";  // "Guest"
  
  let userRole = "Admin";
  let role = userRole || "User";   // "Admin"

How Short Circuit Works:

  AND (&&) - Returns first FALSE value or last value:
  true && true && "Success"      // "Success" (all true, returns last)
  true && false && "Success"     // false (stops at first false)

  OR (||) - Returns first TRUE value or last value:
  false || false || "Default"    // "Default" (all false, returns last)
  false || "Found" || "Default"  // "Found" (stops at first truthy)

Practical Use Cases:

  1. Set default values:
     const color = userColor || "blue";

  2. Conditional rendering:
     const message = isLoggedIn && `Welcome, ${username}!`;

  3. Chain multiple values:
     const theme = userTheme || systemTheme || "light";

  4. Safe function execution:
     isAdmin && performAdminActions();  // Only runs if isAdmin is true


=== QUICK COMPARISON TABLE ===

Operator | Used For           | Returns When           | Ignores
---------|-------------------|------------------------|----------
?. | Access nested props | undefined if value is missing | —
?? | Provide defaults    | Right side only if left is null/undefined | 0, false, ""
&& | Conditional logic   | First falsy or last value | —
|| | Default values      | First truthy or last value | —


=== PRACTICAL EXAMPLE: Using All Three ===

const user = {
    name: "John",
    address: {
        city: "NYC"
    }
};

// Optional chaining + Nullish coalescing
const city = user?.address?.city ?? "Unknown City";  // "NYC"

// With missing property
const user2 = { name: "Jane" };
const city2 = user2?.address?.city ?? "Unknown City";  // "Unknown City"

// Short circuit with conditional
const message = user?.name && `Hello, ${user.name}!`;  // "Hello, John!"


=== KEY TAKEAWAYS ===

1. Use ?. when accessing nested properties safely
2. Use ?? for default values (better than ||)
3. Use && for conditional expressions that should execute
4. Use || when you want the first truthy value
5. Combine them for powerful, clean, readable code!
