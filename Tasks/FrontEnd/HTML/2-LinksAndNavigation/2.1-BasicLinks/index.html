Task 2.1: Basic Links

This page demonstrates different types of links in HTML5.

1. External Link (Absolute URL)

Opens in a new tab using target="_blank" and rel="noopener noreferrer" for security.

Visit Google

2. Internal Link (Relative URL)

Links to another page in the same website using relative path.

Go to Page 2

3. Link with Title Attribute

Hover over the link to see the tooltip (title attribute).

Wikipedia

4. Email Link (mailto:)

Opens the default email client with pre-filled address.

Send Email to contact@example.com

5. Phone Link (tel:)

On mobile devices, this will prompt to make a call.

Call +1-234-567-890

Bonus: Combined Email Link

Email link with subject and body pre-filled.

Email Support with Subject
