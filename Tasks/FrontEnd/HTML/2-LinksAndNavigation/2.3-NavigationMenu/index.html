🧭 Task 2.3: Navigation Menu

Horizontal Navigation Bar Demo

This page demonstrates a professional horizontal navigation menu using the HTML5 <nav> element with an unordered list. The current page is marked as "active" with special styling.

✨ Semantic HTML

Uses the proper <nav> element for better accessibility and SEO.

🎨 Modern Styling

Gradient background with smooth hover effects and active state indication.

📱 Responsive

Adapts to mobile devices by stacking menu items vertically on small screens.

🎯 Active State

Clearly shows which page the user is currently on with distinct styling.

📝 HTML Structure

<nav>
    <ul>
        <li><a href="index.html" class="active">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="services.html">Services</a></li>
        <li><a href="portfolio.html">Portfolio</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>

💡 Key Features Implemented

  • ✅ Used semantic <nav> element
  • ✅ Unordered list with 5 menu items
  • ✅ Links to different pages
  • ✅ Home link marked as "active"
  • ✅ Horizontal layout using Flexbox
  • ✅ Hover effects for better UX
  • ✅ Sticky navigation (stays at top when scrolling)
  • ✅ Responsive design for mobile devices
