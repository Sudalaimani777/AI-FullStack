================================================================================
                            HTML LEARNING NOTES
================================================================================

HTML = HyperText Markup Language
Purpose: Structure and content of web pages
Not a programming language - it's a markup language.

================================================================================
                        1. HTML DOCUMENT STRUCTURE
================================================================================

Basic HTML Template:
--------------------
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Document Title</title>
</head>
<body>
    <!-- Content goes here -->
</body>
</html>

Key Points:
-----------
- <!DOCTYPE html> - Tells browser this is HTML5
- <html> - Root element, wraps entire document
- <head> - Contains metadata, not visible on page
- <body> - Contains visible page content
- Always close tags properly

================================================================================
                        4. SEMANTIC HTML
================================================================================

Why Use Semantic HTML?
----------------------
✓ Better SEO (Search engines understand content)
✓ Accessibility (Screen readers can navigate)
✓ Maintainability (Cleaner, more readable code)
✓ Future-proof (Standards-compliant)

SEMANTIC vs NON-SEMANTIC:
-------------------------
Semantic:    <header>, <nav>, <main>, <article>, <section>, <footer>
Non-Semantic: <div>, <span> (generic containers)

Use semantic tags when possible!

Example Page Structure:
-----------------------
<header>
    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>
</header>

<main>
    <article>
        <h1>Article Title</h1>
        <p>Content...</p>
    </article>
    
    <aside>
        <h2>Related Links</h2>
    </aside>
</main>

<footer>
    <p>&copy; 2026 Company Name</p>
</footer>

Form Structure:
---------------

    <button type="submit">Submit</button>

Input Types:
------------

password    - Hidden password input
number      - Numeric input
tel         - Phone number
url         - URL address
date        - Date picker
time        - Time picker
datetime-local - Date and time
color       - Color picker
file        - File upload
checkbox    - Multiple selections
radio       - Single selection from group
range       - Slider
hidden      - Hidden field
submit      - Submit button
reset       - Reset form button
button      - Generic button

Form Best Practices:
--------------------
✓ Always use <label> tags with 'for' attribute
✓ Group related fields with <fieldset>
✓ Use appropriate input types for validation
✓ Add 'required' attribute for mandatory fields
✓ Use placeholder text as hints, not labels
✓ Provide clear error messages


================================================================================
                        6. HTML TABLES
================================================================================

Basic Table:
------------
<table>
    <thead>
        <tr>
            <th>Header 1</th>
            <th>Header 2</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Data 1</td>
            <td>Data 2</td>
        </tr>
    </tbody>
</table>

Table Attributes:
-----------------
colspan     - Merge columns horizontally
rowspan     - Merge rows vertically
border      - Border size (use CSS instead)
cellpadding - Cell padding (use CSS instead)
cellspacing - Cell spacing (use CSS instead)

Table Best Practices:
---------------------
✓ Use <thead>, <tbody>, <tfoot> for structure
✓ Use <th> for headers (not <td>)
✓ Add 'scope' attribute to headers (row/col)
✓ Use <caption> for table title
✓ Don't use tables for layout (use CSS Grid/Flexbox)

================================================================================
                        8. ACCESSIBILITY (A11Y)
================================================================================

Key Principles:
---------------
1. Use semantic HTML
2. Provide alt text for images
3. Ensure proper heading hierarchy
4. Label all form inputs
5. Ensure keyboard navigation
6. Maintain color contrast
7. Use ARIA when necessary

Alt Text for Images:
--------------------
✓ Do: <img src="cat.jpg" alt="Orange cat sleeping on couch">
✗ Don't: <img src="cat.jpg" alt="image">
✗ Don't: <img src="cat.jpg"> (missing alt)

For decorative images:
<img src="decoration.jpg" alt="">

ARIA Attributes:
----------------
aria-label          - Label for element
aria-labelledby     - Reference to label element
aria-describedby    - Additional description
aria-hidden         - Hide from screen readers
role                - Define element role
aria-live           - Announce dynamic changes

Heading Hierarchy:
------------------
✓ Correct:
<h1>Main Title</h1>
<h2>Section 1</h2>
<h3>Subsection 1.1</h3>
<h2>Section 2</h2>

✗ Wrong:
<h1>Main Title</h1>
<h3>Skip h2!</h3> (Don't skip levels)

Keyboard Navigation:
--------------------
- All interactive elements must be keyboard accessible
- Use Tab to move forward, Shift+Tab to move back
- Use Enter/Space to activate buttons/links
- Provide visible focus indicators


================================================================================
                        9. BEST PRACTICES
================================================================================

Code Quality:
-------------
✓ Use lowercase for tags and attributes
✓ Always quote attribute values
✓ Close all tags properly
✓ Indent nested elements (2 or 4 spaces)
✓ Add comments for complex sections
✓ Keep line length reasonable
✓ One element per line for complex structures

File Organization:
------------------
✓ Use meaningful file names (lowercase, hyphens)
✓ Keep HTML, CSS, JS in separate files
✓ Organize images in 'images' or 'assets' folder
✓ Use relative paths when possible

Performance:
------------
✓ Minimize file size
✓ Optimize images before using
✓ Use lazy loading for images below fold
✓ Defer non-critical scripts
✓ Minimize HTTP requests

SEO:
----
✓ Use descriptive title tags (50-60 characters)
✓ Write compelling meta descriptions
✓ Use heading tags properly (one h1 per page)
✓ Create descriptive URLs
✓ Add alt text to all images
✓ Use semantic HTML


================================================================================
                        10. COMMON MISTAKES TO AVOID
================================================================================

✗ Missing closing tags
✗ Nesting tags incorrectly
✗ Missing alt attributes on images
✗ Using <br> for spacing (use CSS instead)
✗ Using tables for layout
✗ Using too many <div> tags (divitis)
✗ Not using semantic HTML
✗ Inline styles everywhere (use external CSS)
✗ Missing DOCTYPE declaration
✗ Not testing across browsers
✗ Skipping heading levels (h1 to h3)
✗ Using wrong input types for forms
✗ Not labeling form inputs
✗ Forgetting viewport meta tag
✗ Not validating HTML code

                        14. RESPONSIVE DESIGN
================================================================================

Viewport Meta Tag (ESSENTIAL):
-------------------------------
<meta name="viewport" content="width=device-width, initial-scale=1.0">

This tag ensures your page scales properly on mobile devices.

Responsive Images:
------------------
<img src="image.jpg" 
     srcset="image-320w.jpg 320w,
             image-480w.jpg 480w,
             image-800w.jpg 800w"
     sizes="(max-width: 320px) 280px,
            (max-width: 480px) 440px,
            800px"
     alt="Responsive image">

Picture Element:
----------------
<picture>
    <source media="(min-width: 800px)" srcset="large.jpg">
    <source media="(min-width: 400px)" srcset="medium.jpg">
    <img src="small.jpg" alt="Responsive image">
</picture>

-------------
_blank      - New window/tab
_self       - Same frame (default)

HTTP Methods:
-------------
GET         - Request data (visible in URL)
POST        - Submit data (not visible in URL)
