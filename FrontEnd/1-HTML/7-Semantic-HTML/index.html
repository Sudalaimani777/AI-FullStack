Semantic HTML

Learn about meaningful HTML elements that describe content purpose

Topics to Cover:

1. Header and Navigation

  • <header> - Page header (logo, main heading)
  • <nav> - Navigation links

2. Main Content

  • <main> - Main content of the page
  • <article> - Independent, self-contained content
  • <section> - Thematic grouping of content
  • <aside> - Sidebar or related content

3. Footer and Other

  • <footer> - Page footer
  • <figure> - Self-contained illustration/diagram
  • <figcaption> - Caption for figure
  • <time> - Machine-readable date/time
  • <mark> - Highlighted/marked text

4. Semantic vs Non-Semantic

Semantic: <article>, <section>, <header>

Non-Semantic: <div>, <span> (generic containers)

5. Benefits of Semantic HTML

  • Better for SEO (Search Engine Optimization)
  • Improved accessibility for screen readers
  • Cleaner, more readable code
  • Better for web scrapers

6. Example Page Structure

<header>
    <nav>Navigation</nav>
</header>
<main>
    <article>
        <h1>Article Title</h1>
        <p>Content...</p>
    </article>
    <aside>
        <h2>Related Links</h2>
    </aside>
</main>
<footer>
    <p>Copyright...</p>
</footer>
